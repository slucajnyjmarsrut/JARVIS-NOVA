# JARVIS NOVA Python Agent RC4 — обучение без самоповреждения

Приоритет — **улучшение по результатам**, без автоматического выполнения кода из интернета.

1. После команды «Открой Steem» JARVIS сравнивает текст с названиями **реально установленных ярлыков** Windows.
2. Для уверенного и однозначного совпадения с «Steam» показывается вопрос пользователю. Пока пользователь не подтвердил, приложение НЕ открывается.
3. Только после **успешного** запуска обученное название сохраняется в `%LOCALAPPDATA%\JarvisNova\learning-v1.json`.
4. При повторном запросе оно используется автоматически. Нельзя обучить программу запуску PowerShell, cmd, произвольного EXE, URL, файла или shell-команды.
5. Через меню **Самоулучшение** можно обучить названия вручную, посмотреть статистику успешных/неудачных типов действий, удалить одно соответствие или полностью сбросить обучение.
6. Не сохраняются исходные голосовые записи, скриншоты, текст набора, пароли и полные фразы команд. В локальном JSON хранятся **только подтверждённые названия программ** и агрегированные счётчики по типам действий.
7. Модуль НЕ меняет EXE самостоятельно. Чтобы улучшать исполняемый код, нужен проверенный новый релиз и согласие пользователя.

**Это проект RC4 для PyInstaller, не собранный Python EXE.** Для готового Windows EXE с реализованным самообучением используй отдельную сборку **JARVIS NOVA 3.6.2** (Go-версия).
