# JARVIS NOVA 0.5.1-dev — исправление распознавания и главного окна

## Проблема из пользовательского скриншота

- На экране были короткие неправильные записи типа «что ты здесь», «лишь», «Пусть. Пусть.» и ответ «Не понял команду».
- Это было вызвано ранней обработкой неточного текста Vosk как окончательного результата, а также режимом `Офлайн-команды` по умолчанию.
- Надпись `Микрофон выключен` не доказывает, что он записывал речь во время выключения: журнал содержит уже обработанные фразы. Новая версия показывает состояние микрофона отдельно от сообщений AI.

## Что изменилось

1. **Vosk** используется для активации и сегментации; основную транскрипцию завершённой фразы теперь пытается выполнять **Whisper base**. Только если Whisper отсутствует или падает, используется исходный Vosk-текст.
2. Порог начала голосового фрагмента снижен со 125 до 55 (относительные PCM/RMS единицы). Это повышает чувствительность к тихому голосу, но может увеличить влияние фоновых шумов. Гарантии распознавания шёпота нет.
3. **AI-разговор включён по умолчанию.** Неопознанные как действие вопросы идут во встроенную локальную Qwen3-VL 2B, которая отвечает по-русски. Модель не имеет права выполнять Windows-команды и не обращается к облаку.
4. На главном окне видны кнопки микрофона, F9, вопроса, роликов, игр, учёбы, экрана и камеры. Ввод текста имеет кнопку отправки.
5. Статус микрофона показан отдельно. При остановке окно не должно снова показывать `Vosk готов` из старой очереди.
6. Windows CI должен отдельно выполнить `--chat-self-test` с **реальной моделью**, в упакованном EXE и после установки, помимо существующего Whisper/Vision/Silero E2E.

## Как испытать на настоящем Windows

- Установи новую **0.5.1-dev** (НЕ старую 0.5.0) после успешной сборки и скачивания.
- Набери `Кто ты?` в нижнем поле и нажми «Отправить». Первый ответ локальной Qwen может появиться с задержкой при запуске модели.
- Для голоса нажми «Микрофон вкл/выкл», убедись, что отдельный индикатор показывает `Микрофон: включён`, и скажи `Джарвис, кто ты?`. Либо используй F9.
- Для шёпота проверь Windows → Звук → Ввод: нужный микрофон, уровень громкости, отсутствие шумоподавления, съедающего тихую речь. Точный выбор микрофона из GUI пока не реализован.
- «Ролики» и «Игры» теперь вынесены на главную панель. Полный набор команд остался в меню «Режимы».
- Закрой окно по X и проверь Диспетчер задач: после завершения не должны оставаться `JarvisNova.exe` и его дочерняя локальная Ollama.

## Ограничения

Это тестовая сборка. Её успешная GitHub-сборка не заменяет испытание на твоём микрофоне, особенно при тихой речи. При ошибке попробуй тот же вопрос через текст, чтобы разделить проблему ASR и локального AI. Не передавай API-ключи или записи голоса для диагностики: достаточно текста распознанной фразы и ошибки интерфейса.
