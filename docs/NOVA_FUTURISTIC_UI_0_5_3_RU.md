# JARVIS NOVA 0.5.3-dev — Futuristic HUD (Windows)

## Что изменилось

- Полностью новый тёмный HUD (без браузера, WebView и сетевых зависимостей).
- Анимированное векторное ядро NOVA: цвет и подпись определяются **реальным состоянием** голосового движка.
- Слева — управление микрофоном, выбор устройства, тест громкости и активация F9.
- Справа — диалог с цветовой разметкой ролей, поле ввода, восемь быстрых кнопок:
  **Ролики, Игры, Работа, Офис, Учёба, Экран, Камера, Возможности**.
- Индикатор режима AI: встроенная локальная Qwen, только команды, внешняя Ollama
  или облачные API, чтобы пользователь видел, когда выбран сетевой движок.
- Состояния HUD: микрофон отключён, запуск, ожидание «Джарвис», прослушивание,
  обработка, синтез ответа, ошибка устройства.
- Управление клавиатурой: **F9** — слушать; **Ctrl+L** — фокус поля ввода;
  **Enter** — отправить запрос.
- Сохранены все прежние меню: Разрешения, Зрение, Режимы, AI, Самоулучшение.

## Безопасность

Интерфейс **не** включает микрофон самостоятельно, не подменяет разрешения и не
запускает операции без ранее существующих проверок в main.py. Запрос на захват
экрана или камеры по-прежнему каждый раз запрашивает согласие.
Простой анимированный рисунок на Canvas не связан с аудио и не пишет запись в файлы.

## Проверка

- tests/test_nova_ui.py: машина состояний, визуальный статус микрофона,
  создание Tk-виджетов, нажатие кнопки, горячие клавиши, маркировка AI.
- Windows voice-ui smoke: модуль без модели + прежние тесты голосовых команд.
- Windows offline build: настоящая сборка полного установщика со всеми моделями
  (статус проверяйте в GitHub Actions). Автоматические тесты **не** заменяют
  визуальный осмотр на компьютере с реальным экраном, Bluetooth и микрофоном.

Для проверки вручную: запустите JARVIS NOVA, убедитесь, что реактор меняет
состояние при включении и выключении микрофона. Затем протестируйте F9,
ручной ввод текста, выбор устройства, каждую из восьми быстрых кнопок и
отказ от разрешения на камеру/экран.
