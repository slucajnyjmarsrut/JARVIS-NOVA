# JARVIS NOVA — облегчённый установщик без голоса

Эта сборка Windows запускается **только с текстовым интерфейсом**.
Кнопок микрофона и озвучивания нет, а ASR/TTS-модули и их веса не
включаются в распространяемый EXE/установщик.

## Что именно вырезано из установщика

- Голосовые checkpoint-файлы Vosk, Whisper base/small, Silero v5_ru.
- Библиотеки PyTorch/torchaudio/torchvision, Whisper, Vosk,
  sounddevice, pyttsx3 и связанные модули микрофона и TTS.
- Установка тяжёлых моделей речи и три голосовых E2E-цикла в Windows CI.
- Исходные голосовые модули сохранены только в GitHub для исторической
  совместимости, **не в Windows-программе**.

## Что осталось

- **Локальная Qwen3-VL 2B** (примерно 1,9 ГБ модели) через Ollama —
  текстовый диалог и анализ изображений в офлайн-режиме.
- FreeLLM по отдельному выбору и с локально настроенными ключами.
- Программирование на 20 языках, Java/Luau, Roblox Studio,
  генерация карт и glTF/PBR-моделей.
- Видеомонтаж и проверка качества через FFmpeg/FFprobe
  (в том числе **аудиодорожки видео и музыка**, это не голос JARVIS).
- FilmCraft с автоматическим скачиванием после нажатия пользователем.

Локальный Qwen остаётся крупнейшей частью размера. Поэтому новая версия
заметно легче исходной, но **не маленькая**. Размер и SHA256 устанавливаются
только после удачной Windows-сборки, не по предположению.

## Проверки

Windows CI тестирует текстовый интерфейс, голосо-свободный состав пакета,
реальные ответы Qwen и распознавание содержимого тестовой картинки,
реальный FFmpeg-монтаж, упакованный Windows EXE и установку/удаление
с сохранением пользовательских настроек. Голосовые тесты не входят
в выпускной сценарий.

Старые голосовые тесты можно запускать в отдельном окружении по желанию
разработчиков, но они больше не обязательны для сборки этого установщика.

**Внимание:** новая версия в ветке `jarvis` не меняет ветку `main`.
Прямой ввод произвольных команд / автозапуск сгенерированного ИИ-кода
не добавляется.
