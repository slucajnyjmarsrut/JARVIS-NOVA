# JARVIS NOVA 0.5.10-dev — автоматический тихий ответ на шёпот

## Что делает режим

JARVIS автоматически оценивает характер каждой **распознанной** голосовой
команды по её 16-кГц аудиофрагменту в оперативной памяти. Когда человек
говорит шёпотоподобным тихим, слабо озвученным голосом, ответ
озвучивается **существенно тише и мягче**. Если следующая фраза произнесена
обычным голосом, ответ снова звучит с обычной громкостью.

- Пример: тихое «Джарвис, сколько времени?» → тихий ответ.
- Пример: обычное «Джарвис, открой блокнот» → обычный ответ.
- Отдельно переключать режим не нужно.
- Для команд, напечатанных с клавиатуры, громкость обычная.
- После одного ответа тихий режим не навязывается следующему запросу.
- В оверлее при воспроизведении видно, идёт тихий или обычный ответ.

## Как реализовано

- `whisper_mode.py`: анализ RMS только активной части речи и
  периодичности голосовых связок; игнорирует тишину и фрагменты без
  достаточного уровня. Динамически уточняет ориентир громкости при
  уверенной обычной речи.
- `voice_engine.py`: стиль привязан к **конкретной авторизованной**
  фразе после распознавания Whisper (или штатного fallback).
  Не влияет на разрешения, команды экрана/камеры и данные в сети.
- `main.py`: передаёт стиль вместе с голосовой командой через
  GUI-очередь, фиксирует его перед запуском TTS и сбрасывает на обычный
  для независимых GUI-действий.
- `speaker.py`: при тихом ответе усилие Silero уменьшается до 24%,
  аудиосигнал слегка сглаживается; на Windows TTS fallback громкость
  снижается до 25%. Обычные ответы воспроизводятся на 100%.
- Микрофон, Vosk, Whisper, Silero и привязка оверлея работают офлайн.

## Важно: ограничения

**Текущая Silero-модель не умеет настоящую фонаторную речь шёпотом.**
Это «тихий, мягкий ответ» с приблизительной классификацией шёпота,
а не специальный нейросетевой шепчущий голос Алисы.

Шёпот НЕ равен просто низкой громкости: близкий к микрофону громкий
шёпот, очень тихий обычный голос, шум кондиционера или Bluetooth
компрессия могут ошибочно классифицироваться. Это эвристика, без
записи голоса, обучения по пользователю или облачного распознавания.

## Ручная проверка на Windows

1. Нажать F9 или произнести «Джарвис», шёпотом задать вопрос:
   ответ должен быть тихим. Убедиться, что не слушает своё TTS.
2. Повторить обычным голосом: ответ должен вернуться к полной громкости.
3. Проверить очень тихую **обычную** речь: если она остаётся
   голосовой/периодичной, она не обязана считаться шёпотом.
4. Повторить через Bluetooth/USB микрофон и встроенный микрофон;
   при необходимости выбрать вход через главное окно JARVIS.
5. При плохом различении сообщить примерную громкость/тип
   микрофона — нужно будет калибровать пороги по реальным данным.

Windows CI проверяет алгоритм только на синтетических звуках и
мок-моделях (обычная речь / низкий шумоподобный голос). До аппаратного
тестирования точность на настоящем шёпоте **не подтверждена**.
