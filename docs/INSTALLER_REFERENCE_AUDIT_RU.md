## Что перенесено в наш Inno Setup скрипт

Один графический Windows установочный EXE, современный мастер с русским языком, ярлыки, установка в `%LOCALAPPDATA%\Programs\JarvisNova`, запуск после установки, повторные установки, штатная деинсталляция, персистентные настройки в `%LOCALAPPDATA%\JarvisNova`. Для обновления во время работы приложения добавлен общий mutex `JarvisNovaRuntime`. Нет требования прав администратора, Python и Ollama не скачиваются в процессе установки.

Важно: **не пытаться копировать веса из непроверенного исходного установщика**. Это только пример упаковки/интерфейса. Финальный установщик JARVIS NOVA появляется только после полного Windows CI E2E + упаковки + проверки самого инсталлятора.
