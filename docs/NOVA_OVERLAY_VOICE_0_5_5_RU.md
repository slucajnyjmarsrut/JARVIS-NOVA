# JARVIS NOVA 0.5.5-dev — автоматический правый оверлей + голос

## Оверлей при сворачивании/скрытии главного окна

- Сверните главное окно обычной кнопкой Windows: через ~50 мс с правого края
  экрана появляется маленький NOVA HUD поверх обычных окон.
- Через **Интерфейс → Скрыть окно → оверлей справа** или
  **Ctrl+Shift+O** (при активном главном окне) окно можно намеренно скрыть.
- В оверлее отображаются **реальное состояние голоса**, последний уровень
  микрофона в dBFS и активный режим. Никаких дополнительных потоков
  микрофона оверлей не открывает.
- Кнопки **Вкл/выкл микрофон**, **Слушай** и **Окно** используют исходные
  действия с прежней системой разрешений.
- Нажатие **Открыть**, **Окно** или Ctrl+Shift+O при фокусе оверлея
  возвращает главный интерфейс; плавающая панель автоматически исчезает.
- Панель по умолчанию закреплена справа и примерно на 1/3 высоты экрана;
  её можно перетаскивать за заголовок.
- Обычное закрытие большого окна полностью завершает программу,
  **не** прячет её незаметно в фоне.

## Голос: команда не теряется при длительном Whisper

- Пока Whisper обрабатывает предыдущую фразу, до двух следующих
  **активированных** («Джарвис» / F9 / окно продолжения) фраз остаются
  в ограниченной очереди в оперативной памяти.
- После окончания распознавания очередь обрабатывается по порядку;
  сырые гипотезы Vosk по-прежнему не используются для камер и экрана.
- При выключении микрофона очередь очищается. Поздний результат
  уже отменённого сеанса не выполняется после Stop/restart.
- Непрошенные фоновые фразы **не** добавляются в очередь.
- Индикатор «СЛУШАЮ» ориентируется на реальное время окна
  голосовой активации, а не на старую надпись «жду команду».

## Горячие клавиши и ограничения

- F9 — активировать голос, пока фокус в приложении или оверлее.
- Ctrl+Shift+O — скрыть/вернуть главное окно, пока фокус в одном
  из окон JARVIS. **Не** глобальный системный хоткей.
- Ctrl+Shift+M — включить/выключить микрофон в главном окне.
- Доступ к другим программам, Vision и чувствительные действия
  по-прежнему требуют предусмотренных подтверждений.
- Always-on-top не гарантирует отображение поверх игр в
  эксклюзивном полноэкранном режиме.
- Правое закрепление по умолчанию рассчитано на основной экран;
  физические настройки нескольких мониторов ещё не проверены.

## Проверки

Набор Windows CI проверяет Tkinter-окна, автоматический показ после
withdraw, возврат в основное окно, таймер обновления, кнопки,
активацию и очистку ограниченной очереди Whisper. Ни один из этих тестов
не требует доступа к реальным записям пользователя. Настоящий микрофон,
Alt+Tab, игры и сценарии на двух мониторах требуют отдельной проверки
на физическом Windows-компьютере.
