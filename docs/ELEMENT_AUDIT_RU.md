# JARVIS NOVA — поэлементный аудит (ветка jarvis)

## Цель

Проверять каждый доступный элемент по четырём сценариям:
**обычный ввод, неправильный ввод, отмена и сохранность данных**.
Это технический журнал проверок и найденных дефектов, **не сертификат
абсолютной безопасности**. Запуск на реальном пользовательском ПК всё ещё
обязателен перед стабильным релизом.

## Обнаруженные и исправленные дефекты

1. Окно регистрации могло прятать нижние кнопки на небольших экранах.
   Добавлена прокручиваемая область и адаптивная ширина текста.
2. Колесо мыши не прокручивало карточки, потому что события получали
   вложенные элементы. Добавлены локальные биндинги без глобального bind_all.
3. Отмена в середине копирования итогового MP4 не учитывалась.
   Добавлена проверка на каждом блоке и откат MP4 вместе с EDL.
4. Новый EDL не распознавался FilmCraft. Простые монтажные решения теперь
   можно восстановить как отдельные исходные клипы. Сложные эффекты
   открываются как готовый MP4 без ложного утверждения о точной реконструкции.
5. Кнопка «Открыть FilmCraft» могла начать скачивание приложения
   без отдельного подтверждения. Теперь перед сетью есть согласие.
6. Выбранная ранее музыка была скрыта в подтверждении эдита, что могло
   привести к непреднамеренному добавлению аудио. Теперь имя файла видно.
7. Некоторые изменённые модули видеостудии и FilmCraft не попадали в
   фильтр автоматической пересборки Lite. Исправлены CI пути.
8. Добавлены проверки **каждого из 16** фильтров FFmpeg и
   **каждого из 10** переходов, а не только одного демонстрационного ролика.

## Самостоятельное повторение тестов

В проверенной среде Python с зависимостями приложения:

- \`python scripts/run_text_only_tests.py\`
- \`python -m unittest discover -s tests -p test_popular_edits.py -v\`
- \`python -m unittest discover -s tests -p test_creator_accounts.py -v\`
- \`python -m unittest discover -s tests -p test_filmcraft_bridge.py -v\`
- \`python -m unittest discover -s tests -p test_ollama_pull_client.py -v\`

Для полного FFmpeg теста нужны доступные \`ffmpeg\` и \`ffprobe\`.
Без них соответствующие реальные рендеры будут **пропущены**,
а не пройдены. В Lite CI эти зависимости устанавливаются и
обязательные видеотесты выполняются повторно.

## Остаточные ограничения

- Автоматические тесты не подтверждают фактический внешний вид каждой
  кнопки на всех размерах экрана/масштабировании Windows.
- Не проверена на реальном ПК работа со всеми видеокодеками, повреждёнными
  контейнерами, сверхбольшими исходниками и драйверами видеокарт.
- Не доказана способность Qwen завершить 1.9 ГБ скачивания при конкретном
  VPN или плохом интернете; проверены сетевые сбои и восстановление.
- Не проверена фактическая регистрация аккаунтов — она выполняется
  владельцем на официальных сайтах, без чтения паролей и CAPTCHA JARVIS.
- «Все популярные виды монтажа» здесь — **16 готовых пресетов**, а не
  бесконечный список и не полная замена профессионального видеоредактора.
- Сертификат разработчика для обновлений JARVIS ещё не закреплён:
  автоматическая установка неподписанного релиза преднамеренно отключена.
- GitHub Actions на виртуальных Windows не заменяет испытание установщика
  на чистом физическом компьютере и независимую проверку безопасности.

**Все исправления выполняются исключительно в ветке \`jarvis\`.**
