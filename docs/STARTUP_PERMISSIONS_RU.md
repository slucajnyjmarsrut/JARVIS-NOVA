# JARVIS NOVA — управление и зрение по умолчанию

В Windows **при первом запуске** JARVIS NOVA доступ к управлению мышью, клавиатурой, окнами и к анализу экрана **включён по умолчанию**, без запроса разрешений. В статусе JARVIS видно, включены ли оба права. Само включение доступа **не делает снимок экрана, не начинает запись и не выполняет команды**.

Снимок экрана создаётся только по отдельной команде пользователя. Если доступ включён, повторный диалог для каждого снимка не появляется. JARVIS не запускает постоянное наблюдение за экраном.

В настройках (F10) → «Разрешения» можно в любой момент нажать «Отозвать разрешения». Это сразу отключает оба права и сохраняет отключение для всех следующих запусков текущей учётной записи Windows. Если захочешь вернуть доступ, нажми «Всегда разрешать управление и зрение» и подтверди его включение.

Пользовательский выбор хранится в профиле Windows в зашифрованном DPAPI-файле: `%LOCALAPPDATA%/JarvisNova/startup_permissions.bin`. Сохранённый отказ важнее настроек по умолчанию. Повреждённая или подменённая запись отключает доступ. **Удаление файла сбрасывает настройки к новому запуску и снова включает права по умолчанию**; для отзыва пользуйся только штатной кнопкой JARVIS. Если запись отзыва не удалась, JARVIS показывает ошибку и сообщает, что отключение действует только до закрытия программы.

Доступ к ПК и экрану **не отменяет** ограничений на удаление/перезапись файлов, запуск сгенерированного кода, скачивание моделей, отправку данных в облачные ИИ, публикацию или другие действия с отдельным подтверждением.

Проверка: `python -m unittest discover -s tests -p test_startup_permissions.py -v`.
