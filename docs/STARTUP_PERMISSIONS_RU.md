# Разрешения JARVIS NOVA при каждом запуске

По умолчанию JARVIS не имеет разрешения на управление ПК и зрение.

В настройках (F10) открой «Разрешения» и выбери «Всегда разрешать управление и зрение». После однократного явного подтверждения JARVIS включит оба права в текущем сеансе и автоматически восстановит их при следующем запуске под той же учётной записью Windows.

Разрешается штатный контроль мыши, клавиатуры и окон, а также анализ экрана по запросу пользователя локальной моделью. Доступ к экрану **не** означает постоянной записи или фонового наблюдения. Отдельные запросы конкретного снимка и опасные действия по-прежнему могут потребовать дополнительного подтверждения.

Согласие шифруется Windows DPAPI в профиле текущего пользователя: %LOCALAPPDATA%/JarvisNova/startup_permissions.bin. Если запись отсутствует, повреждена, подменена или не может быть расшифрована, разрешения отключены. Для другого пользователя Windows запись не действует.

Чтобы отключить сейчас и на будущих запусках, выбери «Отозвать разрешения». Если сохранённую запись не удалось изменить, JARVIS предупреждает: разрешения будут отключены только до закрытия, а файл надо удалить вручную до следующего запуска.

Это разрешение **не** охватывает удаление/перезапись файлов, установку моделей, выполнение кода, доступ к облачным ИИ, публикацию видео и другие самостоятельные опасные действия. Для них действуют собственные правила.

Проверка: python -m unittest discover -s tests -p test_startup_permissions.py -v
