# JARVIS NOVA → FilmCraft: одно нажатие, автоматическое скачивание

**FilmCraft больше не нужно скачивать и устанавливать вручную.**

1. Открой JARVIS NOVA и его «Видео-студию».
2. По желанию создай ролик через «АВТОМОНТАЖ».
3. Нажми **«🎬 FILMCRAFT — СКАЧАТЬ И ОТКРЫТЬ»**.
4. Если редактор уже установлен, JARVIS сразу откроет его. Если нет,
   он автоматически скачает официальную портативную версию FilmCraft
   **v0.18.0** (около 110 МБ), проверит SHA-256, распакует в папку
   пользователя, затем откроет программу и передаст текущий монтаж.
5. В FilmCraft продолжай ручной монтаж на профессиональной шкале,
   сохраняй проект в .fcproj и экспортируй обновлённый MP4.

Скачивание запускается **только при нажатии кнопки**, не при открытии JARVIS
и не в фоне. Есть процент загрузки/распаковки. Повторные нажатия не
скачивают программу заново. Интернет нужен только при первом запуске.

## Куда устанавливается

Портативная версия распаковывается без прав администратора:

\`%LOCALAPPDATA%\JARVIS-NOVA\FilmCraft\v0.18.0\`

Исходные проекты JARVIS, фильмы и проекты FilmCraft не перезаписываются.
Если в этой папке уже есть неизвестные файлы, автоматическая установка
остановится вместо удаления данных. Другие установленные версии FilmCraft
из PATH, Program Files или указанного пути также распознаются.

## Откуда скачивается и почему это безопаснее

Источник строго закреплён за официальным релизом GitHub:
https://github.com/storytold/filmcraft/releases/tag/v0.18.0

- Архив: \`filmcraft-0.18.0-windows-x64-portable.zip\`.
- Размер: **109616261 байт**.
- Ожидаемый SHA-256:
  \`82847cf49087e95fd3f72dde80955d1c63af2821ad677e34e3de7a0e873e95bf\`.
- Проверяются HTTPS и адреса GitHub при перенаправлениях.
- Распаковка не допускает выхода из папки, символических ссылок и
  чрезмерного размера архива. Повреждённый архив не запускается.
- Не запускаются PowerShell-скрипты из интернета, нет запросов прав
  администратора, ключей API или автоматической публикации роликов.
- Встроенные средства Windows (например, SmartScreen) не отключаются.

Если GitHub недоступен, программа не скачивается, и JARVIS сообщает об
ошибке. Можно повторно нажать кнопку после восстановления интернета.

## Как JARVIS передаёт монтаж FilmCraft

Если доступны исходные клипы и \`filmcraft-cli.exe\`, JARVIS создаёт
новый редактируемый проект \`.fcproj\` через монтажную шкалу \`.otio\`.
На видеодорожке находятся отдельные нарезки оригиналов, на звуковой —
результат сведения JARVIS; переходы перенесены как OTIO-переходы, а
сценарные подписи доступны через маркеры.

Если создать проект не удалось, JARVIS откроет готовый MP4. Такой ролик
можно редактировать, однако текст и эффекты уже «запечены» в видео.
Самостоятельная ручная правка оригиналов доступна через полученный OTIO.

**FilmCraft работает как отдельное окно-редактор**, а не встраивается в
пиксели интерфейса JARVIS. Сам JARVIS продолжает отвечать только текстом:
микрофон и его озвучивание отключены.

JARVIS не распространяет FilmCraft от своего имени; он скачивает
официальную версию по запросу пользователя. FilmCraft — сторонняя
программа в стадии alpha. Работоспособность на конкретной Windows
зависит от устройства, системных библиотек и этой версии редактора.
