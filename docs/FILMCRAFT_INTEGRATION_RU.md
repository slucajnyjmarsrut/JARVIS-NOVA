# JARVIS NOVA → FilmCraft: нажми кнопку и продолжай монтаж

JARVIS остаётся текстовым помощником, его озвучивание и микрофон отключены.

## Для пользователя Windows

1. Установи официальный FilmCraft отдельно: https://getfilmcraft.org/download
   (программа бесплатная и открытая, но пока находится в alpha).
2. Запусти JARVIS NOVA, открой **Видео-студию**.
3. По желанию дай JARVIS автоматически собрать ролик.
4. Нажми **«🎬 ОТКРЫТЬ FILMCRAFT — РУЧНОЙ МОНТАЖ»**.
5. FilmCraft откроется самостоятельно. Редактируй кадры, переходы,
   титры, цвет, музыку на профессиональной монтажной шкале.
6. Сохраняй работу как **.fcproj** и экспортируй отдельный MP4 из FilmCraft.

Кнопка также есть в главном меню JARVIS: **FilmCraft — открыть редактор**.
Можно нажать её даже до автомонтажа: запустится пустой FilmCraft.

## Что открывается после автомонтажа

Если у установленной версии рядом с filmcraft.exe есть **filmcraft-cli.exe**,
JARVIS создаст **новый редактируемый .fcproj** через официальный CLI:
- Видеодорожка V1 содержит исходные отрезки из сохранённого
  монтажного листа JARVIS (если файлы ещё на месте).
- Аудиодорожка A1 ссылается на готовый MP4 с музыкальной
  подложкой и сведением звука.
- Переходы между кадрами сохраняются как OTIO-переходы.
- Текст сценарных титров добавляется в маркеры для ручной доработки.
- Файл .otio остаётся рядом с MP4 и может быть импортирован вручную.

**Важно:** эффекты FFmpeg, анимированные титры, точная обработка звука и
цвет могут не переноситься в монтажную шкалу FilmCraft один к одному.
Их результат остаётся в готовом MP4 для сравнения, а оригинальные
клипы доступны для более тонкой ручной обработки в FilmCraft.

Если FilmCraft CLI не установлен, создание проекта не сработало или
исходники перенесены, JARVIS откроет **готовый MP4** в FilmCraft.
Он редактируем как обычный видеоклип, но переходы и титры уже
«запечены» в изображение. Чтобы вручную импортировать исходные
нарезки, используй **Файл → Импорт…** и созданный .otio (если он есть).

## Безопасность и настройка

JARVIS ищет установленный FilmCraft в:
- %LOCALAPPDATA%\Programs\ArtCraft\FilmCraft\filmcraft.exe;
- %ProgramFiles%\ArtCraft\FilmCraft\filmcraft.exe;
- в PATH, либо по пути JARVIS_FILMCRAFT_EXE.

Если редактор не найден, JARVIS попросит выбрать filmcraft.exe;
ничего не скачивает и не устанавливает автоматически.

FilmCraft запускается только после нажатия на кнопку — через список
аргументов Windows, без shell и без исполнения команд от внешней модели.
Исходные кадры и готовый MP4 не перезаписываются.
Для каждого нового запуска создаётся новый проект FilmCraft, чтобы
не потерять ручные изменения предыдущего сеанса.

FilmCraft и ArtCraft — независимые сторонние проекты, не входят в
установщик JARVIS. Доступность, точность импорта и качество эффектов
зависят от версии FilmCraft и исходного материала.
