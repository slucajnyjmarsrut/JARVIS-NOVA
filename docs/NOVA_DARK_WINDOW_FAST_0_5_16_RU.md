# JARVIS NOVA 0.5.16-dev — тёмное окно и быстрые ответы

## Исправления после скриншота пользователя

**Было:** сверху светлое меню Windows, светлая полоса заголовка и
белый скролл справа при полностью тёмной NOVA-панели.

**Стало:**
- Убрали нативную горизонтальную верхнюю строку `Разрешения / Зрение / ...`.
  Все пункты и команды сохранены под кнопкой **«НАСТРОЙКИ / F10»**
  в верхней части ЛЕВОЙ NOVA-панели.
- На Windows 10/11 запрашивается тёмная системная строка заголовка
  через штатный `DwmSetWindowAttribute`. Кнопки закрытия, разворота и
  сворачивания остались системными и рабочими. Старые сборки Windows,
  не поддерживающие этот атрибут, могут оставить исходный цвет заголовка.
- Правая прокрутка беседы теперь `ttk.Scrollbar` со стилем `clam`
  и тёмными оттенками, без белой полосы Windows.
- Левый rail и окно диалога остались тёмными, без дополнительных
  верхних панелей.

## Время ответа

Для точных повседневных вопросов/фраз «Привет», «Как дела»,
«Что делаешь», «Спасибо», «Как ты», «Здравствуй» JARVIS отвечает
локально сразу, без запуска тяжёлой Qwen. Это **не** используется
для составных вопросов, запуска приложений или системных действий.
Вопрос «Как дела с проектом?» всё равно передаётся модели.
Для прочих вопросов верхний предел ответа уменьшен до 72 токенов,
контекст до 1536 токенов; диалог остаётся в RAM.

## Распознавание речи

Версия 0.5.16 содержит все изменения 0.5.15: второй декодирующий
проход Whisper для низкой уверенности, устранение ошибочного
обучения шумового порога от ползунка и видимый текст **РАСПОЗНАНО**
в левой панели. Если распознано неверно, модель всё ещё может
ошибаться — в зависимости от микрофона, профиля Bluetooth и шума.
Данные микрофона не сохраняются на диск.

## Проверка после установки

1. Убедись: верхнего светлого меню нет. Открой **НАСТРОЙКИ / F10**
   слева, убедись, что старые функции доступны.
2. Открой длинный диалог: справа полоска прокрутки должна быть тёмной.
3. Нажми F9, скажи «Как дела?» — ответ должен последовать быстро.
4. Нажми F9, скажи «Что делаешь?» и сравни строку
   **РАСПОЗНАНО** с произнесённой фразой.
5. Вопрос «Расскажи историю» запустит Qwen и может отвечать дольше,
   особенно на CPU; скорость зависит от настоящего устройства.
6. Камера по-прежнему удалена, анализ экрана остался по разрешению.

Тесты Windows CI проверяют API и виджеты, но физическую запись
русской речи и видимость тёмного заголовка на конкретном мониторе
надо проверять на самом ПК.
