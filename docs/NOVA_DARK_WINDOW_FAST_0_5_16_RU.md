# JARVIS NOVA 0.5.16-dev — тёмное окно без белых полос, быстрые ответы

## Исправления после пользовательского скриншота

1. **Белая строка меню сверху удалена.** Разрешения, зрение,
   режимы, AI, интерфейс, самообучение, остановка микрофона —
   теперь открываются кнопкой **⚙** в левой панели.
   Функции меню не удалены.
2. **Системная строка заголовка Windows переводится в тёмный режим**
   через DWM (цвет фона, заголовка, границ) там, где Windows
   поддерживает эти атрибуты. Окно остаётся обычным: сворачивание,
   разворачивание, Alt+Tab, Snap и изменение размера сохранены.
   На очень старых сборках Windows, где DWM игнорирует настройку,
   системная рамка может остаться светлой.
3. **Прокрутка чата** больше не использует светлый системный Tk Scrollbar.
   Теперь это тёмный бирюзовый ttk/clam Scrollbar.
4. **Левая панель сама прокручивается.** На экране 760–800 пикселей
   доступны все кнопки, даже когда список длиннее высоты окна.
   Колёсико над панелью и узкая полоса слева пролистывают её.
5. Основные внутренние отступы уменьшены, чтобы диалог вмещался
   лучше даже при небольшом экране.

## Ускорение ответов

- Простые точно определённые фразы («как дела?», «что делаешь?»,
  «привет», «спасибо», «кто ты») получают короткий готовый
  **локальный ответ мгновенно**, без запуска тяжёлой модели Qwen Vision.
  Настоящие команды и содержательные вопросы не перехватываются
  по отдельным словам или похожим фразам.
- Для остальных вопросов Qwen получила лимит до 72 токенов вместо
  112 и более короткий контекст. Она по-прежнему остаётся на устройстве.
  Реальная скорость зависит от CPU, оперативной памяти и самого вопроса.
- Системный запрос уточнён: JARVIS не должен выдумывать, что смотрит
  на экран, слушает музыку или выполняет программы. Если распознан
  бессмысленный текст, ассистент должен попросить повторить.
- Улучшения распознавания русского из 0.5.15 — сохранены
  (повторное уточнение сомнительных фраз и исправленный микрофонный порог).

## Проверка установки

1. Установить 0.5.16 поверх предыдущей dev-версии.
2. Проверить, что не осталось постоянного белого меню.
3. Открыть **⚙** слева и проверить все прежние функции.
4. Прокрутить вниз левую панель до нижних быстрых действий.
5. Пролистать историю чата — справа не должно быть белой полосы.
6. Произнести через F9 «как дела?», затем «что делаешь?»,
   сравнить скорость отклика до и после обновления.
7. Проверить обычные команды («открой блокнот») и длинный
   вопрос — их должен обрабатывать прежний механизм разрешений
   и локальная модель соответственно.

## Важные ограничения
Windows CI моделирует голос и проверяет Tk интерфейс, а полный
Windows installer проверяет встроенные модели на синтетическом
вводе. **Точность настоящего микрофона и вид заголовка на каждом
компьютере автоматически не подтверждаются.**
