# JARVIS NOVA — ПРОФЕССИОНАЛЬНЫЙ МОНТАЖ V2 (jarvis)

Это инструкция для редактора JARVIS NOVA в Windows. Описывает реальные
возможности кода, не выдавая их за Premiere Pro или After Effects.

## 1. Эдит по готовому стилю

Выбери **«Видео-студия» → «Эдиты»**. Доступны 16 готовых направлений,
среди них TikTok, Shorts, Reels, AMV, Velocity, Gaming, Vlog,
Cinematic, Travel, Meme, Product, Noir, Retro и Dreamy.

JARVIS собирает настоящее видео H.264/AAC из 1–10 локальных файлов.
Форматы 9:16, 16:9, 1:1, 4:5, 10 типов переходов и цветовые фильтры.
FFmpeg не получает сгенерированные нейросетью команды.

## 2. Редактируемый таймлайн

Выбери **«Таймлайн · клипы / скорость / титры / переходы»**
в меню **⚙**, либо кнопку таймлайна в видеостудии.

1. **+ Клип** — выбери до 10 собственных MP4/MOV/MKV/WEBM/AVI/M4V.
2. Кликни по клипу в списке или **перетащи блок мышью по шкале**, чтобы изменить порядок. Каждое перемещение можно отменить.
3. Настрой **точку начала в исходнике**, длину готового фрагмента
   (0.75–15 секунд), скорость **0.5–2×** и титр выбранного фрагмента.
4. Нажми **«Применить к клипу»**. Можно также разделить один фрагмент
   на два в точной точке, продублировать, удалить и переставить кадры.
5. **«Отменить / Вернуть»** хранит до 30 шагов редактирования в памяти.
6. **«Показать выбранный кадр»** использует локальный FFmpeg.
   Это предварительный кадр исходника, **не финальный просмотр
   музыки, субтитров и переходов**. После экспорта нажми
   **«Просмотреть готовый MP4»**, чтобы открыть полный результат
   в обычном системном видеоплеере Windows (только после нажатия).
7. Выбери отношение сторон, цветокоррекцию и один из 10 переходов;
   настрой длительность перехода (0–0.45 секунды).
8. При желании выбери собственную музыку, регулируй её громкость.
9. При наличии собственных субтитров добавь файл **UTF-8 SRT**.
   Поддерживается до 24 реплик в одном 90-секундном ролике;
   они будут точно привязаны ко времени на таймлайне и
   нарисованы локально через Pillow. Облачное распознавание
   речи и автоматические субтитры **не заявляются**.
10. Укажи **новый MP4**, подтверди экспорт. JARVIS собирает и
    перепроверяет результат через FFprobe: видео H.264, звук AAC,
    правильное разрешение, длительность и существование файла.
    Пока идёт FFmpeg, окно показывает анимацию и прошедшее время,
    остаётся доступной кнопка **«СТОП»**. Это не вымышленный
    процент готовности и не гарантия фиксированной скорости обработки.
11. Можно сохранить проект кнопкой **«Сохранить проект JSON»**,
    открыть его снова и продолжить редактирование.
12. После экспорта можно сразу открыть **«Дальше: слои / озвучка»**,
    **FilmCraft** или помощник подготовки публикации.
    При передаче в FilmCraft без автоматического скачивания используются
    существующие локальные файлы. Простые склейки с обычной скоростью
    могут быть импортированы как редактируемые исходные клипы; при
    ускорениях, сложных переходах и SRT откроется только
    **готовый MP4**, потому что эти эффекты нельзя честно восстановить
    простой нативной склейкой другого редактора.

Таймлайн содержит не более 10 клипов и итоговую длительность до
90 секунд. Длительность исходного отрезка должна быть достаточно
большой для выбранной скорости. Если файл короткий, проект не
рендерится и оригинал не изменяется.

## 3. Многодорожечный монтаж

Открой **«Многодорожечный монтаж»** или продолжи после таймлайна.

- Основной собственный MP4.
- До **трёх наложений**: видео поверх видео, PNG/JPG/WEBP,
  логотипы и другие пользовательские графические элементы.
- Для каждого наложения — время начала и длительность,
  пять позиций, размер 10–70% ширины, прозрачность 10–100%.
- Шесть заранее настроенных анимаций: неподвижно, плавное появление,
  въезд слева/справа, движение вверх/вниз. Скорость анимации настраивается.
  Это базовые ключевые кадры движения, **не** свободный редактор кривых.
- Дополнительная опция звука: автоматически приглушать фоновую музыку,
  когда звучит озвучка (FFmpeg sidechain compressor). По умолчанию выключена;
  доступна только если выбраны обе дорожки.
- Сверху можно добавить графический титр.
- Отдельные музыка и озвучка смешиваются с исходным звуком.
  Если у исходника нет звука — создаётся тихая дорожка.
- Настройка громкости музыки от 0 до 0.7.
- Локальный экспорт нового MP4, проверка H.264/AAC и JSON
  \`_MULTITRACK.json\`.
- Отдельные кнопки **«Сохранить проект» / «Открыть проект»**
  дают возможность поменять слои и экспортировать новую версию.

Это последовательный рабочий процесс: сначала клипы и субтитры
на таймлайне, потом наложения и голос. Видеофайл между этапами
остается локальным и проходит проверку.

## 4. Подготовка публикации

Открой **«Подготовить публикацию»**. JARVIS предложит выбрать
YouTube / TikTok / Instagram, добавить название, описание, хештеги,
сформирует **локальный JSON-черновик** с SHA-256 видео, а по явному
подтверждению откроет официальный кабинет в обычном браузере.
Публиковать видео, вводить пароль, SMS, CAPTCHA и настройки
видимости должен владелец аккаунта.

## 5. Защита проектов и безопасные ограничения

- Все исходники открываются **только на чтение**.
- Экспорт и JSON сохраняются под **новыми именами**;
  существующие видео и проекты не перезаписываются.
- В случае ошибки/отмены частично созданные итоговые файлы удаляются.
  Временные промежуточные файлы очищаются.
- Загружаются только допустимые типы файлов с ограничениями размера
  и длительности. Для SRT — проверка времени **относительно длительности
  финального монтажа до начала FFmpeg**. Прямой модуль вшивания SRT
  также запрещает перезапись исходного или существующего MP4.
- Видео не отправляется в облако. Скачивание других редакторов
  требует отдельного подтверждения.
- Нет скрытого подключения соцсетей или автозагрузки.
- Оригинальные клипы не удаляются, не переименовываются
  и не меняют содержимое.
- Все GitHub-изменения только в ветке **jarvis**; main не меняется.

## 6. Проверки и неготовые функции

Автоматические тесты:

- \`python -m unittest discover -s tests -p test_popular_edits.py -v\`
- \`python -m unittest discover -s tests -p test_video_timeline.py -v\`
- \`python -m unittest discover -s tests -p test_subtitle_tracks.py -v\`
- \`python -m unittest discover -s tests -p test_multitrack_composer.py -v\`
- \`python scripts/run_text_only_tests.py\`

В Lite Windows CI реальные тесты рендеров запускаются с
проверенными FFmpeg и FFprobe. Тест без доступного FFmpeg
может быть пропущен на машине разработчика; это **не успех реального
рендера**. Результаты Windows 2022/2025 и тестов установщика
следует смотреть для конкретного нового commit SHA.

**Честные ограничения:** Это уже полноценный редактор для коротких
социальных роликов из своих файлов, но **не** полный функциональный
эквивалент CapCut, DaVinci Resolve, Premiere/After Effects. Здесь
нет интерактивного покадрового GPU-превью готового монтажа,
motion tracking, масок с узлами, ручных кривых keyframe,
цветовой профессиональной grading-панели, автоматической
расшифровки речи и облачного совместного редактирования.
Те функции требуют отдельных движков, UI и тестирования.

Установщики DEV из GitHub Actions сами по себе не являются
подписанными стабильными релизами. Для безопасной автоматической
установки нужен проверенный цифровой сертификат издателя.
