# JARVIS NOVA — общая прокачка и аудит модулей (PR #6)

## Охват

Репозиторий содержит **263 Python-файла**: 122 корневых модуля,
119 тестовых файлов и 22 скрипта (на момент этого обновления).
`python scripts/audit_module_health.py` выполняет read-only проверку
синтаксиса **каждого** из этих файлов без запуска кода, доступа к экрану,
скачивания моделей или отправки данных.

Проверяются наличие главных компонентов в **девяти** группах:
модели, сценарии, генерация кода, видео, зрение, Supervisor,
разрешения, интерфейс и установщики.

Важно: синтаксическая проверка **не означает**, что все функции работают,
все модели установлены, результаты нейросетей точны или EXE готов к выпуску.

## Что действительно улучшено

1. **Скачивание моделей:** `ollama_pull_client.py` корректно принимает
   закрытие HTTP-потока во время отмены. Ошибки соединения по-прежнему
   считаются ошибками; отсутствие подтверждённого ответа *success*
   не выдаётся за завершённую загрузку.
2. **Окно отдельных моделей:** `task_ai_hub.py` обновляет элементы Tk
   только из главного потока. Фоновые проверки Ollama и разрешённые
   загрузки используют очередь UI-событий.
3. **Автономный Supervisor:** `night_supervisor.py` передаёт сигнал
   паузы в FFmpeg-рендер из темы. Отмена сохраняет последнюю
   проверенную контрольную точку, не объявляет задачу выполненной и
   не переписывает пользовательские файлы.
4. **Видео с нуля:** `topic_video_engine.py` теперь строит графику по
   конкретным инструкциям каждого кадра, а не только по заголовку.
   Это исходная моушн-графика, **не** фотореалистичный генератор видео.
5. **Интеграционные тесты:** `tests/test_cross_module_reliability.py`
   проверяет закрытие потока модели, потокобезопасность Tk,
   прерывание и восстановление рендера, различия кадров.
6. **Общий аудит:** `scripts/audit_module_health.py` и
   `tests/test_module_audit.py` включены в CI Windows 2022/2025,
   Lite и полную сборку.

## Как проверить

```powershell
python scripts/audit_module_health.py
python -m unittest discover -s tests -p test_cross_module_reliability.py -v
python -m unittest discover -s tests -p test_module_audit.py -v
python -m unittest discover -s tests -p test_supervisor_always_on.py -v
python -m unittest discover -s tests -p test_topic_video_engine.py -v
```

## Что не доказано этими тестами

Реальная многочасовая работа всех пяти моделей на одном ПК,
качество фотореалистичного видео, функциональная корректность
сгенерированных проектов и полный пользовательский цикл
в новом установщике требуют отдельных проверок.
Текстовая сборка намеренно не содержит голосовых моделей — исторические
модули речи в репозитории не означают наличие функций микрофона в EXE.

Никакие изменения PR #6 не должны сливаться в `jarvis`
без отдельного решения владельца репозитория.
