# JARVIS NOVA 0.5.12-dev — веб-камера полностью удалена

Начиная с 0.5.12 в Windows JARVIS NOVA **нет функции работы с веб-камерой**.

## Что удалено
- Кнопка «КАМЕРА» в интерфейсе NOVA HUD.
- Пункт меню вопросов к веб-камере.
- Голосовой маршрут «что перед камерой / посмотри в камеру».
- Файл `camera_capture.py` с `cv2.VideoCapture`, захват JPEG и
  зависимость OpenCV (`opencv-python`) из Windows requirements и PyInstaller.
- Поддержка источника `camera` в `TriModalPipeline` и `TrimodalService`.
- Возможность запустить обычную камеру Windows через команду
  «открой/включи камеру» внутри JARVIS.

Любой прямой запрос к удалённому источнику `camera` теперь
**отклоняется до открытия микрофона, чтения экрана и запуска модели**.

## Что оставлено
- Голосовой помощник, Vosk, Whisper, Silero, режим шёпота,
  переподключение микрофона и разговор с Qwen.
- Анализ **снимка экрана** по отдельному разрешению. Это не веб-камера.
- Видеостудия: сценарии, работа с существующими роликами, монтаж с FFmpeg,
  YouTube/TikTok идеи. Она не захватывает изображение с устройства камеры.
- Игры, рабочие режимы, правый оверлей.

## Что проверить
1. Главный интерфейс должен показывать «ЭКРАН», но не «КАМЕРА».
2. Запрос «Джарвис, открой камеру» должен сказать, что функция удалена.
3. «Джарвис, посмотри на экран» должна спрашивать отдельное разрешение.
4. Монтаж готовых видео по-прежнему должен открываться через «РОЛИКИ».
5. Windows сборка не должна содержать импорт OpenCV для веб-камеры.

Это новая dev-ветка; ранее скачанные установки 0.5.11 сохраняют старый
код и должны быть обновлены до 0.5.12. Код не меняет системные
разрешения Windows для других приложений: удаление только в JARVIS NOVA.
