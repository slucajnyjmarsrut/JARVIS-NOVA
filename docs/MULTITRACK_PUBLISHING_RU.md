# NOVA MULTITRACK + ПОДГОТОВКА ПУБЛИКАЦИИ (ветка jarvis)

## Что теперь можно сделать без Qwen и интернета

В меню JARVIS выбери **«Многодорожечный монтаж · видео/логотип/звук»**
либо в видеостудии **«МНОГОДОРОЖЕЧНЫЙ МОНТАЖ»**.

Новый редактор умеет:

1. Взять существующий MP4 до 90 секунд в качестве основы.
2. Наложить до **трёх видеодорожек/картинок** на разные временные
   интервалы (в текущем окне есть два поля, движок поддерживает три).
3. Расположить слой в одном из пяти положений; настроить время начала
   и длительность. API рендера также задаёт размер и прозрачность.
4. Добавить титр на видео (локальный Pillow, Unicode).
5. Добавить **две независимые звуковые дорожки**: фон и озвучку,
   смешивая их с оригинальным звуком или тишиной.
6. Собрать H.264/AAC MP4 через локальный FFmpeg без передачи исходников
   в сеть и без необходимости загружать Qwen.
7. Проверить длительность, кодеки и размер через FFprobe.
8. Сохранить новый MP4 и отдельный JSON-монтажный лист
   \`_MULTITRACK.json\`, без перезаписи ранее существующих файлов.
9. Отменить работу, после чего неполный MP4 и черновой JSON не остаются.

**Ограничение:** многодорожечный редактор пока не имеет полноценной
визуальной тайм-линии, кривых анимации, motion tracking или полного
ручного набора эффектов Adobe Premiere/After Effects. В отличие от
простого монтажного листа FilmCraft, многодорожечный JSON в этой версии
предназначен для просмотра/архива, а не для гарантированного импорта
в нативную тайм-линию сторонней программы.

## Как подготовить публикацию

Выбери в меню **«Подготовить публикацию»**, либо одноимённую кнопку
в видеостудии. JARVIS предложит:

- выбрать собственный готовый MP4;
- выбрать YouTube / TikTok / Instagram;
- заполнить название, описание и хештеги;
- создать **локальный JSON-черновик** с SHA-256 исходного файла,
  без создания второй тяжёлой копии видео;
- скопировать подпись в буфер обмена;
- с отдельным согласием открыть **официальный** кабинет:
  - YouTube Studio — \`https://studio.youtube.com/\`
  - TikTok Studio — \`https://www.tiktok.com/tiktokstudio\`
  - Instagram — \`https://www.instagram.com/\`

**Публикации не происходит автоматически.** На официальном сайте
пользователь сам входит в аккаунт, выбирает MP4, проверяет авторские
права, настройки видимости и завершает загрузку.

Полноценная авторизованная автопубликация потребует отдельных
интеграций OAuth, разрешений от платформ, безопасного хранения токенов,
подтверждения содержания/площадки, лимитов запросов и механизма
повтора/отмены публикации. Пока эти условия не реализованы,
автопубликация намеренно недоступна. JARVIS не собирает пароли и
SMS-коды и не обходит CAPTCHA. **Автоматическая регистрация аккаунтов
также остаётся функцией ручной регистрации на официальных сайтах.**

## Тесты

- \`python -m unittest discover -s tests -p test_multitrack_composer.py -v\`
- \`python -m unittest discover -s tests -p test_creator_publish.py -v\`
- \`python scripts/run_text_only_tests.py\`

Windows Lite CI повторно запускает тесты после установки доверенного
FFmpeg. Реальные тестовые рендеры используют сгенерированные
неавторские фрагменты, наложения и аудио, не загружают пользовательские
материалы.

Это проверка конкретных сценариев, а не доказательство полной
безопасности: стабильная подписанная версия всё ещё требует отдельной
проверки. Все изменения и коммиты находятся **только в ветке jarvis**,
не в main.
