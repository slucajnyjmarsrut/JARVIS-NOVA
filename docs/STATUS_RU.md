## Направление

- Интегрированная локальная RC4-ветка включает `trimodal_service.py`, `bundled_vision_runtime.py`, `screen_capture.py`, `offline_e2e_test.py`, Windows Inno Setup / PyInstaller конфигурацию.
- В локальном коде модель Vision изменена с `gemma3:4b` на `qwen3-vl:2b-instruct` как **непроверенная гипотеза** уменьшения установщика; затем на `qwen3-vl:2b-instruct` для прямого ответа.
- Публикация CI и перенос всех файлов — отдельный незавершённый этап. Этот репозиторий на момент документа ещё не содержит полного локального пакета.
- Доступ к GitHub не равен доступу к чистой Windows, камере, реальным checkpoint и подписывающему ключу.

## Нельзя объявлять релиз

Пока нет реального распознавания русской речи Whisper, Vision-вопроса с изображением, синтеза Silero, физического испытания Windows и подтверждённого SHA256 финального установщика.
