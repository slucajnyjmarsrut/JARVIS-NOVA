# JARVIS NOVA — проверенные результаты Windows CI (18.10.2026)

## Фактические достижения

- Windows runner успешно скачал и инициализировал реальные Whisper base, Silero v5_ru и Vosk small ru.
- Реальная последовательность `Silero PCM (русский вопрос) → Whisper транскрипция → Qwen3-VL 2B Vision (JPEG красного квадрата) → Silero PCM ответа` прошла без модельных заглушек.
- Vision ответил: **«Квадрат на изображении красный.»**
- Реальный PyInstaller Windows x64 EXE успешно прошёл те же синтетические проверки со встроенными моделями.
- Inno Setup реально собрал единый DEV-установщик (2 157 013 005 байт, SHA-256 `30FE02D18A7296A5BDA8C7101B7B1F617B6B8966C5A7B05C69100F4A04AA72A3`) в предыдущем Windows CI, **но эта сборка не сохранила EXE в опубликованном артефакте**.
- Причина падения предыдущей установки: синтаксическая ошибка PowerShell `$Mode:` — исправлена коммитом `1dcb5c5`.
- Следующая сборка столкнулась с ограничением анонимного GitHub API при получении Ollama; исправлена GitHub-авторизацией в CI.

Документальные доказательства: [лог успешного реального инференса и компиляции Inno Setup](https://github.com/slucajnyjmarsrut/JARVIS-NOVA/actions/runs/39112152920). Текущая [полная Windows-сборка](https://github.com/slucajnyjmarsrut/JARVIS-NOVA/actions/runs/39121200942).

## Чего это не доказывает

Не подтверждены живой микрофон, вебкамера, Bluetooth, воспроизведение на физическом ПК, закрытие X и работа на чистой Windows 10/11 без подготовки. Не объявлять полноценный публичный релиз до проверок. Следить за успешным результатом установщика и опубликованным файлом — один прошедший этап компиляции сам по себе не гарантирует получение пользователем EXE.

Сборки выполняются в отдельной ветке `dev/trimodal-integration-2026-10`, не в `main`.
