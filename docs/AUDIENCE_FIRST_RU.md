# JARVIS NOVA — новый режим: сначала аудитория, затем ролик

**Стадия разработки.** Это исходники новой Видео-студии, НЕ новый протестированный EXE. Старый установщик не содержит этих функций. Подключение к аккаунтам и публикация пока не выполняются.

## Последовательность

1. Владелец канала выгружает аналитический CSV в YouTube Studio → Аналитика → Расширенный режим → экспорт CSV. Программа спрашивает разрешение прочитать **конкретный локальный файл**; пароль, cookie и ключи не нужны.
2. Модуль **аналитики** проверяет реальную историю роликов (название, просмотры; необязательно — лайки, комментарии, CTR, среднюю долю просмотра) и находит повторяющиеся темы у лидеров. Не выдумывает данные, которых нет.
3. Специализированные модули: **аналитик аудитории**, **редактор тем**, **эксперт первых секунд**, **эксперт удержания**, **редактор публикации**. Их выводы опираются на экспорт, где это возможно, и помечают общие эвристики.
4. Локальная Qwen пишет оригинальный сценарий и съёмочный лист; голос JARVIS может сказать, что снять. Сценарий составляется **после** анализа канала, а не на общих трендах вместо аудитории.
5. После съёмки пользователь указывает папку со своими файлами 01.mp4, 02.mp4 и т. д. FFmpeg собирает локальный MP4 (9:16, титры, звуковая дорожка).
6. На **последнем шаге**, после реального монтажа, `video_forecast.py` проверяет полученный MP4 через ffprobe, длительность, наличие звука, первые секунды, темп, титры и совпадение темы с успехами канала. Сохраняет `FINAL_AUDIENCE_REVIEW_RU.md` и `FINAL_AUDIENCE_REVIEW.json` с индексом соответствия 0–100 и советами.

## Важное о «популярности»

Индекс 0–100 **не означает 80% вероятности вирусности**. Это проверяемая, но пока не обученная на будущих успехах оценка соответствия аудитории. У платформ нет публичного точного «процента захода», который можно честно вычислить без обратной связи. Исторический диапазон просмотров выводится только при наличии не менее трёх прошлых роликов с похожей темой — и подписывается «не прогноз».

Алгоритм не знает демографию, комментарии и видео-зрительское удержание поминутно, если этих данных не было в CSV. Специалисты программные, а не настоящие нанятые эксперты.

## Доступ, приватность и ограничения

- Данные канала читаются **локально**; в локальную Qwen идут только агрегаты. Никаких отправок на чужие AI-сервисы, публикаций и передачи паролей.
- Подключение YouTube Analytics API с OAuth только на чтение — следующий этап. Для реального подключения потребуются согласие владельца, безопасная авторизация и проверка. TikTok/Reels в этой стадии работают только через подходящий CSV.
- Нужны минимум 3 ролика и два столбца: `Title`/`Video title` (рус. `Название`) и `Views` (`Просмотры`).
- Свежие поисковые тренды Google по желанию могут дополнять аналитику — не подменять её.

## Тестирование

В репозитории: `python -m unittest discover -s tests -p test_audience_first.py -v`; Windows workflow `viral-studio-smoke.yml`.

На реальном Windows пользователь должен дополнительно испытать: импорт своего CSV, создание сценария через локальную модель, озвучивание, видеомонтаж, итоговый отчёт и работу интерфейса. Код этой стадии не гарантирует, что выпуск нового EXE уже собран.
