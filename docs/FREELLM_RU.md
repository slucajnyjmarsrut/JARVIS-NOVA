# JARVIS NOVA — FreeLLM (только текст)

**Что подключено:** официальный протокол OpenAI-compatible FreeLLM / `freelm serve`.
В меню JARVIS: **AI → FreeLLM · несколько ИИ**. По умолчанию JARVIS
по-прежнему использует свою локальную Qwen; FreeLLM включается только
после подтверждения передачи сообщений внешним провайдерам.

## Установка FreeLLM на своём компьютере (Windows)

Например, пакет [freelm](https://github.com/shihabshahrier/freelm) предоставляет
локальный API `http://127.0.0.1:4000/v1` с автоматическим выбором бесплатных
моделей и переключением провайдеров.

1. Установите Python и выполните `py -m pip install freelm`.
2. Создайте собственные API-ключи у провайдеров FreeLLM (Gemini, Groq,
   OpenRouter и т. д.). Привяжите их к **локальному процессу FreeLLM** через
   поддерживаемые им переменные окружения (например, `GEMINI_API_KEY`).
3. Запустите локальный FreeLLM: `freelm serve --port 4000`.
4. Запустите JARVIS NOVA, откройте меню AI, выберите **FreeLLM** и
   подтвердите, что текст может направляться внешним моделям.

Другие OpenAI-compatible шлюзы FreeLLMAPI тоже поддерживаются. Если адрес
другой, установите переменную `FREELLM_BASE_URL` (обязательно локальный
`http://127.0.0.1:ПОРТ/v1`). Обязательная авторизация шлюза:
`FREELLM_API_KEY` — единый ключ, **не** ключ самого Gemini/Groq.
`FREELLM_MODEL=auto` и `FREELLM_CODE_MODEL=auto` задают псевдонимы
моделей для чата и программирования соответственно.

**GitHub хранит исходный код JARVIS, но не выдаёт сторонние API-ключи.**
Нельзя класть секреты в публичные файлы репозитория, коммиты,
релизы или Windows-установщик. Secrets в GitHub Actions недоступны для
пользовательского приложения и не должны встраиваться в EXE.
Не пересылайте реальные ключи в чат или issue.

## Режим спора

В меню **⚙ → Режим спора — вкл/выкл** или сообщением
«Давай поспорим» включается добровольный режим дискуссии для Qwen
и FreeLLM. JARVIS отвечает контраргументами по существу, задаёт
уточняющие вопросы, отделяет факты от мнений и может признать,
что пользователь прав. Это **не** автоматическое отрицание всех тезисов.

«Хватит спорить» отключает режим, «Режим спора?» показывает состояние.
По умолчанию режим выключен и не сохраняется на диск. Команды Windows,
запись файлов, генерация программ и разрешения не меняются.
Для содержательного диалога нужна доступная Qwen или FreeLLM.

## Безопасность и ограничения

- JARVIS подключается только к локальному FreeLLM, без переходов по URL,
  с ограниченными по размеру ответами. FreeLLM сам обращается к провайдерам.
- Код проекта передаётся внешней модели только после отдельного
  подтверждения в окне генерации. Изменения в файлах по-прежнему требуют
  просмотра и подтверждения.
- Тексты переписки находятся только в памяти программы (последние 4 пары
  сообщений); ключи не пишутся в проект или логи.
- Никакой голос и микрофон не включаются.
- При недоступности FreeLLM переключитесь в меню AI на локальную Qwen.
  Качество моделей и бесплатные лимиты не гарантированы.
