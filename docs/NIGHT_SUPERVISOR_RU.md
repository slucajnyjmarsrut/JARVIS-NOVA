# Автономная ночная работа JARVIS NOVA — версия DEV

Supervisor — отдельный программный контролёр с постоянной очередью, не нейросеть с неограниченными правами Windows. Меню: «Автономная ночная работа · Supervisor».

Поддерживаются только:
1. Сценарии Gemma3:4b: независимая структурная проверка, шаблон без ИИ не считается успешным.
2. Новые проекты Python: установленная локальная Coder-модель, шаги построения, независимый анализ Python AST. Код не исполняется; успешная проверка синтаксиса не доказывает функциональность.
3. Текстовые монтажные советы Llama3.2:3b для сценария этой очереди (можно добавить в очередь после него). Это не сборка MP4.

Перед каждой задачей пользователь подтверждает использование локальной установленной модели и создание новых файлов в домашней папке JARVIS-NOVA-Projects/Night-Supervisor/outputs/. Модели не скачиваются. Никаких произвольных ОС-команд, удаления, перезаписи существующих файлов, доступа к экрану, установки ПО, внешнего поиска/загрузки медиа, выполнения сгенерированного кода и публикаций.

Порядок: открыть меню → выбрать тип → описать задачу → подтвердить разрешение → добавить в очередь → подтвердить запуск очереди. Советы по монтажу принимают 32-символьный ID завершённой задачи со сценарием. Нужны работающая Ollama и установленные модели. Компьютер должен оставаться включённым, без сна, а JARVIS — запущенным. Запуска после перезагрузки Windows и пробуждения ПК нет.

SQLite night_jobs.sqlite3 хранит журнал, разрешения и контрольные точки с SHA-256. На сбое выполняемая задача переводится в paused и возобновляется только по новому разрешению, используя сохранённый ответ модели. Повреждённые checkpoints приводят к блокировке. Уже существующая выходная папка никогда не перезаписывается; частичные файлы остаются пользователю. Paused и blocked не считаются успешным завершением. Пауза проверяется между этапами, а не посреди запросов модели.

Лимит одного запуска: 12 задач, до шести часов между этапами. Результат требует человеческой оценки. Real-model E2E и чистая Windows остаются необходимыми до стабильного выпуска.

Проверка без сети и моделей:

    python -m unittest discover -s tests -p test_night_supervisor.py -v
