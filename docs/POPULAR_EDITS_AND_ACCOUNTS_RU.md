# JARVIS NOVA — эдиты, популярный монтаж и соцсети

## Что реализовано в ветке jarvis

Открой **⚙ → «Эдиты · Shorts / TikTok / Reels / AMV»** или
**«Видео-студия» → «ЭДИТЫ · 16 ПОПУЛЯРНЫХ СТИЛЕЙ»**.

JARVIS создаёт настоящий MP4 через локальный FFmpeg из собственных файлов
пользователя. Для этих режимов не требуется ни Qwen, ни интернет.

Доступные готовые стили:

| Режим | Соотношение сторон | Действительные приёмы |
|---|---|---|
| YouTube Shorts | 9:16 | Быстрая нарезка, яркий цвет |
| TikTok edit | 9:16 | Короткие кадры и slide-переходы |
| Instagram Reels | 9:16 | Тёплый цвет и мягкий dissolve |
| AMV / эдит | 9:16 | Контраст и fade-to-black |
| Velocity | 9:16 | Чередование замедления 0.65x и ускорения 1.8x |
| Gaming highlights | 16:9 | Игровые фрагменты, wipe |
| Cinematic | 16:9 | Киношный цвет, длинные кадры и dissolve |
| Vlog / YouTube | 16:9 | Натуральный цвет, спокойные склейки |
| Travel | 9:16 | Тёплый цвет, круговой переход |
| Обучение / обзоры | 16:9 | Длинные отрывки, жёсткая чистая склейка |
| Подкаст / интервью | 1:1 | Квадрат и спокойный ритм |
| Meme / Funny | 9:16 | Быстрые короткие склейки |
| Retro | 4:5 | Выцветшие тёплые оттенки и светлый fade |
| Реклама продукта | 4:5 | Холодный цвет и плавное движение |

| Noir / Ч/б | 16:9 | Чёрно-белый контраст и затемнение |

Эти стили используют фиксированные параметры скорости, цвета и
FFmpeg-переходов — не произвольные команды от ИИ.

## Как создать эдит

1. Собери **1–10 своих видеоклипов** в одну папку. Поддерживаются MP4,
   MOV, MKV, WEBM, AVI и M4V. Кадры идут по именам файлов.
2. Выбери стиль в видеостудии.
3. При желании укажи **свою музыку, на которую имеешь права**.
4. Нажми **«СОБРАТЬ ЭДИТ ИЗ СВОИХ КЛИПОВ»**.
5. Укажи папку с оригиналами и **новый MP4 вне этой папки**.
6. Подтверди монтаж. JARVIS создаст MP4 и отдельный
   \`<имя>_EDL.json\` с решением по каждому исходному клипу.
7. Открой готовое видео в FilmCraft для дополнительных ручных правок.

Оригиналы не заменяются и не удаляются. Уже существующий готовый MP4
или монтажный лист не перезаписываются. Отмена прекращает процесс, а
временные файлы не публикуются. Перед сохранением проверяются аудио
AAC, видео H.264, разрешение и длительность по FFprobe.

**Рамки реализации:** Это пакет готовых эдитов, а не полный аналог
Premiere/CapCut/After Effects. Многослойные эффекты, ручные кривые
скорости, motion tracking, точные субтитры по речи и неограниченные
шаблоны пока требуют дальнейшей разработки или доработки в FilmCraft.
Эдит-пресеты не обещают вирусность и не скачивают чужую музыку.

## Создание аккаунта YouTube, TikTok, Instagram

В главном меню ⚙ открой **«Аккаунты YouTube · TikTok · Instagram»**
либо одноимённую кнопку в видеостудии.

В этом окне JARVIS:

- Объясняет этапы регистрации каждой площадки.
- По явному нажатию кнопки открывает *фиксированный официальный сайт*
  в обычном браузере:
  - YouTube: \`https://www.youtube.com/channel_switcher\`.
  - TikTok: \`https://www.tiktok.com/signup\`.
  - Instagram: \`https://www.instagram.com/accounts/emailsignup/\`.
- Может предложить четыре латинских варианта @имени для единого бренда.
  Наличие свободного имени не проверяется и не гарантируется.

**Важно:** JARVIS **не создаёт аккаунты без пользователя**. Личные
данные, дата рождения, email, пароль, CAPTCHA, проверочный SMS-код,
2FA и согласие с условиями вводятся самим владельцем на официальном
сайте. JARVIS ничего из этого не собирает, не хранит и не отправляет.
Нет автоматического создания множества аккаунтов, обхода ограничений,
публикации контента или доступа к существующим аккаунтам.

Возможность публикации с подключёнными аккаунтами, OAuth и
подтверждением каждого поста — отдельная следующая задача.

## Безопасность и проверка

- Изменения внесены **только в ветку \`jarvis\`**, не \`main\`.
- Программы для монтажа не получают права изменять исходники JARVIS.
- Пользователь выбирает выходной файл; исходные видео не перезаписываются.
- Каждый стиль — фиксированная безопасная комбинация фильтров,
  без \`shell=True\` и без выполнения ИИ-сгенерированных команд.
- Тесты \`tests/test_popular_edits.py\` и
  \`tests/test_creator_accounts.py\` проверяют формат видео, отсутствие
  перезаписи и безопасные ссылки.
- Windows Lite GitHub Actions отдельно запускает настоящий
  FFmpeg-рендер с доверенным встроенным видеодвижком.

Сборка GitHub Actions не заменяет проверку визуального качества на
пользовательском Windows-ПК и не делает DEV-установщик подписанным.
