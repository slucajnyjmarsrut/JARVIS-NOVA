# JARVIS NOVA — режим только текста

JARVIS NOVA теперь запускается через `python bootstrap.py`, `python main.py`
или собранный Windows EXE **только с текстовым интерфейсом**.

- Печатай сообщения в строке ввода, нажимай Enter или «Отправить».
- Ответы показываются в истории переписки. Приложение не озвучивает текст.
- Кнопки микрофона, прослушивания и индикаторы речи убраны с основного
  экрана и мини-панели. В мини-панели также можно набирать сообщения.
- При запуске не создаётся ни объект микрофона, ни синтезатор речи.
- Java, Roblox Luau, локальная Qwen, Windows-команды, видео и анализ
  экрана по текстовому вопросу сохранены.
- Видео-студия получает `speaker=None`, чтобы не озвучивать свои события.

Устаревшие модули и тесты голосовых функций пока остаются в репозитории
для совместимости и регрессионной проверки; приложение их не запускает.
Сборочный процесс пока может упаковывать прежние модели речи — отдельная
оптимизация размера пакета не входит в это изменение.

Примечание: наличие аудиодорожки в видео пользователя не является
голосом JARVIS — видеомонтаж по-прежнему обрабатывает звук самого видео.
