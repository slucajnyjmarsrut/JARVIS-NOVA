## 1. Что строим и где

**JARVIS NOVA** — локальный голосовой AI-ассистент для **Windows 10/11 x64**, на русском языке, с интерфейсом NOVA HUD. Главные требования пользователя:
- Комплект **одним офлайн-установщиком EXE**: конечному пользователю не надо ставить Python, скачивать модели, настраивать API или пользоваться терминалом.
- **Максимально точное понимание обычной и тихой русской речи без крика**, разумная скорость отклика, активация «Джарвис» и F9.
- Ответы голосом через **Silero**, при шепотоподобной входной речи — мягко и тише, при обычной речи — обычная громкость.
- Чистый **тёмный**, зрительно согласованный интерфейс: основная NOVA-панель **СЛЕВА**, без светлого верхнего меню и белой полосы прокрутки; мини-оверлей тоже слева.
- Локальный чат с Qwen, Windows-команды с разрешениями, режимы Игры / Работа / Офис / Учёба, отдельная видеостудия для готовых файлов и FFmpeg.
- **ВЕБ-КАМЕРА ПОЛНОСТЬЮ УДАЛЕНА** и не должна возвращаться; анализ **экрана** разрешён как отдельная opt-in функция.
- Пользователь предпочитает реальные изменения в репозитории, тесты и рабочий EXE, а не повторяющиеся предложения/планы.

## 3. Техническая архитектура

Основные файлы (ориентироваться по свежему коду, названия могут измениться):
- \`main.py\` — приложение Tkinter, маршрутизация голосового ввода, Tk GUI-очередь, состояния, разрешения, настройки.
- \`nova_ui.py\` — тёмная NOVA-панель **слева**, диалог справа от неё, настройка чувствительности, индикаторы; меню «НАСТРОЙКИ / F10» размещено слева.
- \`nova_overlay.py\`, \`overlay_commands.py\` — плавающая **левая** панель при сворачивании; voice show/hide.
- \`voice_engine.py\` — PortAudio/sounddevice микрофон, нормализация пакетов в PCM16 16 кГц, Vosk (wake), буфер начала/конца речи, Whisper, очередь, reconnect, отмена устаревших задач.
- \`speech_capture.py\` — адаптивный уровень речи, порог и усиление целой фразы.
- \`asr_quality.py\` — обработка неопределённости распознавания и ограниченная проверка второй моделью/проходом.
- \`whisper_mode.py\` — эвристика шёпотоподобной речи для снижения громкости ответа; **не генерация настоящего шёпота**.
- \`speaker.py\`, \`speech_output.py\` — Silero TTS, мягкое начало/конец, тихие ответы, короткие части длинного текста.
- \`local_chat.py\` — локальная Qwen через loopback Ollama, короткие ответы, мгновенные ответы на ТОЧНЫЕ короткие приветствия.
- \`agent_core.py\`, \`desktop.py\` — безопасные ограниченные Windows действия, подтверждения, запрет произвольного shell.
- \`trimodal_service.py\`, \`trimodal_pipeline.py\` — Whisper → Vision screen → Silero, **только экран**, не веб-камера.
- \`viral_studio.py\`, \`viral_studio_ui.py\` и связанные файлы — сценарии и монтаж существующих видео FFmpeg.
- \`build_models.py\`, \`verify_models.py\` — скачивание/checksum настоящих offline checkpoint НА СБОРЩИКЕ.
- \`jarvis_nova.spec\`, \`bootstrap.py\` — Windows PyInstaller onedir; затем упаковка Inno Setup.
- \`installer/JarvisNova.iss\` — **один** тёмный Inno Setup 6.6+ EXE, иконки и branded art.
- \`scripts/generate_installer_art.py\` — локальный генератор тёмных BMP иллюстраций, без внешних картинок.
- \`.github/workflows/voice-ui-smoke.yml\` — быстрый тест Windows GUI/voice.
- \`.github/workflows/windows-offline.yml\` — настоящая полная и долгая Windows-сборка.
- \`scripts/test_installer.ps1\` — silent install, model E2E, uninstall, сохранение пользовательских данных.

**Модели распознавания**: \`base.pt\` и **многоязычная \`small.pt\`**, Vosk small-ru-0.22. Для активной русской команды режим **«Точнее»** по умолчанию использует Whisper small; меню **НАСТРОЙКИ / F10 → Распознавание речи** выбирает **«Быстрее · Whisper base»**, если на CPU слишком медленно. Не путать модель для ASR с \`Qwen\`, которая отвечает на вопросы, и \`Silero\`, которая произносит ответ.

## 4. Что уже сделано по этапам

- Базовый NOVA GUI, reactor HUD, голосовая активация, F9, микрофон, Vosk, Whisper, Silero, локальная Qwen, управление окнами, режимы.
- Видео: отдельная студия сценариев, аудитории, оценки и монтажа готовых видеороликов через FFmpeg.
- HUD-показания реального уровня микрофона и выбора устройства; тест входного сигнала.

- **Веб-камера полностью удалена** в 0.5.12: нет \`camera_capture.py\`, \`opencv-python\`, \`cv2.VideoCapture\`, маршрута камеры и кнопки камеры; старые голосовые просьбы открыть камеру блокируются.
- Тихая речь: динамическая чувствительность/шумовой порог, 700 мс pre-roll, оконная нормализация перед Whisper.
- 0.5.14: слева основная/всплывающая панель; Qwen быстрее; прогрев модели Whisper; ползунок чувствительности.
- 0.5.15: более осторожная перепроверка сомнительных русских фраз, строка «РАСПОЗНАНО», исправление подсчёта фона отдельно от усиления.
- 0.5.16: убрано светлое горизонтальное меню, тёмная прокрутка, тёмный нативный заголовок Windows (если ОС поддерживает), доступ к командам через настройки слева; мгновенные ответы на строго совпадающие приветствия.
- **0.5.17**: добавлена настоящая Whisper **small** для повышения точности русского ввода, официальный checksum, режим small/base и CI проверка установленной программы.

## 6. Какие действия РАЗРЕШЕНЫ / ЗАПРЕЩЕНЫ самому JARVIS

Разрешено **без дополнительных запросов**:
- Распознавание активированного пользователем микрофона, локальная речь и чат, открытие настроек и встроенных режимов.
- Локальная проверка устройств и тест микрофона по явной кнопке.
- Использование выбранного пользователем аудиовхода.
- Анализ обычных текстовых запросов Qwen на \`127.0.0.1\`.

Требует явного разрешения в приложении:
- Управление мышью, клавиатурой, окнами; ограниченные действия через \`Desktop\`.
- Анализ **экрана**: отдельное согласие перед снимком, локальная обработка в памяти.
- Иные значимые действия согласно проверке типа команды; AI-планы требуют подтверждения.

ЗАПРЕЩЕНО:
- Включать/использовать веб-камеру любым способом; восстанавливать \`camera_capture.py\` или OpenCV webcam backend.
- Самостоятельно запускать произвольный PowerShell/cmd/скрипты, удалять файлы, покупать товары, обходить разрешения, исполнять подсказку из содержимого экрана как команду.
- Передавать голос/экран на внешние облачные службы в рамках автономного голосового режима; тайно сохранять аудио.
- Считать ошибочно распознанную фразу действительной командой без разрешённой активации и обязательных проверок.

**Важно:** разрешение на управление ПК внутри JARVIS — это пользовательская runtime-проверка в приложении, **не** разрешение новому ChatGPT без вопросов управлять компьютером владельца или его аккаунтами.

## 7. Как работать следующему ChatGPT с GitHub

- Если GitHub подключён — использовать доступный GitHub connector, читать файлы на \`feat/russian-whisper-small-2026-10\`, проверить состояние workflow/артефактов. Не предполагать доступ в новой беседе: подключение может потребовать подтверждения пользователя.
- Внести исправления в **новую feature/fix ветку** от самой свежей успешной версии; не переписывать историю и не изменять default/main не спросив.
- Делать настоящий код + изолированные unit-тесты на каждое изменение; не ограничиваться общими советами.
- Прогонять минимум \`python -m unittest discover -s tests -v\` на CI Windows, а затем полноценный \`.github/workflows/windows-offline.yml\`; новая ветка должна быть включена в триггеры workflow, если это необходимо.
- Проверить, что \`build_models.py\` скачивает настоящие checkpoints с проверкой digest, \`verify_models.py\` их загружает, \`jarvis_nova.spec\` комплектует и что \`scripts/test_installer.ps1\` проверяет установленное приложение и uninstall.
- Полный установщик не готов, пока workflow не завершился **success** и \`Artifacts\` не содержит проверенный файл. Указывать пользователю ссылки на конкретный run, не придумывать sandbox EXE и номер tests.
- При создании GitHub Releases учитывать лимиты файла; не заменять полноту офлайн-установщика заглушкой.
- Изменения в коде разрешены намерением пользователя «улучшай JARVIS», однако критические решения, внешние отправки, удаление пользовательских данных, закупки и публикация от имени владельца требуют отдельного согласования.
- Никаких приватных токенов, секретов, паролей, личных записей или реальной речи в репозитории и тестовых логах.
