# Критерии выпуска одного Windows EXE

1. Получить официальные доверенные веса Whisper `base.pt`, Silero `v5_ru.pt`, мультимодальной Vision-модели и встроенный переносимый рантайм. Проверить SHA-256, условия распространения и полный состав DLL.
2. На Windows x64 выполнить реальный Whisper → Vision → Silero с синтетическим русским аудио и изображением **без моков**. Тест должен проверять смысл Vision-ответа.
3. Вызвать микрофон и камеру/экран с разрешениями, воспроизвести ответ Silero, проверить исключение собственного голоса из распознавания.
4. Собрать PyInstaller onedir и единый установочный EXE, обеспечив всё необходимое без сети при первом старте.
5. Испытать на чистой Windows 10/11 x64 без Python и Ollama, проверить работу установщика/обновления/удаления, команды Windows, закрытие по X без оставшихся процессов.
6. Зафиксировать SHA-256 EXE, список файлов и версии моделей. Не публиковать установщик как готовый продукт при любой недостающей проверке.

**Предостережение:** размер установщика с Vision-весами может превысить ограничения выбранного формата. Подбор более лёгкой модели не является доказательством её качества или совместимости.
