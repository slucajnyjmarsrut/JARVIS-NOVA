# JARVIS NOVA: текстовая Windows-версия без голоса и озвучки

## Изменения PR #6

JARVIS теперь использует **только текстовый ввод и текстовые ответы**.
Удалены голосовой движок, захват с микрофона, распознавание речи (ASR),
синтез ответа (TTS), голосовой режим Whisper/Silero/Vosk, голосовая
телеметрия, кнопки микрофона, устаревшая сборка `jarvis_agent.spec`,
скрипты подготовки голосовых моделей, 19 голосовых тестовых файлов и
девять документов старого голосового режима.

Отдельная **дорожка диктора/озвучки** также удалена из многодорожечного
монтажного редактора: интерфейс, объекты проекта и граф обработки FFmpeg
не создают такой дорожки. Существующие JSON-проекты с явно заданной
озвучкой/приглушением музыки под диктора **не будут молча импортированы**.
Это важно: старые проекты остаются на диске, но требуют нового проекта
без озвучки для экспорта.

**Что оставлено намеренно:** оригинальный звук импортированного
видео, фоновая инструментальная музыка, синтетические инструментальные
тоны для ролика из темы, проверка звука и вывод H.264/AAC.
Это не говорящий JARVIS и не генерация дикторской речи.

При обновлении установщик удаляет только ограниченный список
устаревших *программных* аудиомодулей и весов из директории
установленного приложения. Пользовательские видео, музыка, проекты,
локальный кеш моделей, настройки и `%LOCALAPPDATA%` не удаляются.
Проверка отсутствия старых модулей включена в Windows CI и
синтаксический аудит всех файлов Python.

## Подсистемы, оставшиеся после удаления голоса

- JARVIS Desktop — ввод команд в текстовом чате, открытие программ,
  окно/мышь/клавиатура, только в пределах сохранившихся разрешений.
- Vision — захват/анализ изображения по явному запросу и разрешению;
  постоянный снимок экрана без нового задания не начинается.
- Chat — отдельный локальный Qwen3 через Ollama.
- Code — локальный Qwen2.5-Coder, структура проекта, синтаксические и
  изолированные проверки, ограниченное автоматическое исправление.
- Scenarios — отдельная Gemma3 и проверка пятисценного сценария.
- Video — FFmpeg-редактор, титры, музыка и MP4 без голосового выхода.
  Ролик по одной теме строится из анимированной оригинальной графики;
  **фотореалистичная нейрогенерация видео пока не реализована**.
- Supervisor — фоновая ограниченная очередь, контроль ОЗУ, диска,
  контрольные точки, автоматическое восстановление и ручная пауза.
- Установка — Lite, офлайн и автозапуск Supervisor при входе в Windows.

## Цель качества 8–9/10

Оценка качества каждой нейросети **не может быть установлена только по CI**.
«Успех сборки» означает, что конкретные тестовые контракты прошли; он не
доказывает хорошее понимание живого экрана, настоящую работоспособность
большой сгенерированной программы или монтаж на уровне видеоредактора.
Для честной оценки 8–9 нужны реальные, повторяемые испытания на ПК
владельца: локальные модели установлены, задачи от начала до конца,
проверка экспорта, задержек/ОЗУ и ночного восстановления.
Без них соответствующие модули остаются непроверенными, а не «9/10».
