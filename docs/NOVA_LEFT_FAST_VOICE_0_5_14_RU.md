# JARVIS NOVA 0.5.14-dev — ЛЕВАЯ NOVA-ПАНЕЛЬ / БЫСТРЫЙ ГОЛОС / ТЁМНЫЙ УСТАНОВЩИК

## Для пользователя

- NOVA HUD перенесён на **левую сторону**. Главные кнопки голосового ввода,
  выбора микрофона, теста сигнала, громкости входа и рабочих режимов
  теперь в левой панели. Верхняя полоса с названием/часами перенесена
  туда же. Основное поле диалога занимает остальное место.
- При сворачивании маленький плавающий оверлей появляется **слева**.
  Панель можно перетаскивать; кнопка «⇤» возвращает её к левому краю.
- Ползунок **«Чувствительность» 0.75–2.00×** меняет только уровень,
  используемый для локального поиска начала речи, а не глобальные
  настройки Windows. При шуме не нужно выставлять максимум сразу.
- Whisper получает команду быстрее: русская модель `base.pt` загружается
  заранее в фоне, параллельные команды переиспользуют один экземпляр,
  подбор слов ускорен уменьшением beam до 2. Это компромисс:
  в некоторых шумных условиях beam 5 мог быть точнее.
- Qwen отвечает короче: `think: false`, `num_predict:112`,
  `num_ctx:2048`, модель остаётся в локальной памяти до 20 минут.
  На слабом ПК скорость по-прежнему зависит от CPU/ОЗУ и модели.
- Установщик Inno Setup 6.6+ принудительно открывается в тёмной теме
  `WizardStyle=modern dark` и использует сине-бирюзовые оригинальные
  NOVA изображения. Никакой загрузки картинки из интернета во время
  сборки: `scripts/generate_installer_art.py` сам создаёт BMP.
- Веб-камера **по-прежнему полностью удалена** из приложения и
  установщика; анализ экрана по разрешению и видеомонтаж остаются.

## Как проверить

1. Установи версию 0.5.14 после успешной Windows Actions сборки.
2. Убедись, что **слева** NOVA-панель и режимы, сверху нет старой шапки.
3. При сворачивании отдельная NOVA-панель тоже должна быть **слева**.
4. Скажи «Джарвис, открой блокнот», попробуй F9 → «открой блокнот».
5. Если слова теряются, выбери правильное входное устройство, проверь
   тест RMS и сдвигай ползунок 1.00 → 1.25 → 1.50, сохраняя шумовую
   устойчивость. Сохранять секреты/голосовые данные не требуется.
6. Скажи несколько обычных и тихих фраз, сравни скорость и точность
   с версией 0.5.13 на одном и том же устройстве.
7. Открой мастер установки: тёмный фон, бирюзовый реактор, логотип NOVA.

## Что ещё нужно

- Windows CI измеряет логику и файлы сборки; **оно не измеряет
  скорость на конкретном процессоре** и не проверяет акустику гарнитуры.
- Настоящий нейросетевой VAD в эту версию не включён: используется
  адаптивный gate из предыдущего этапа. Нельзя обещать безошибочное
  распознавание шёпота, Bluetooth и речи в шумной комнате.
- Полная офлайн-сборка остаётся dev/unverified и доступна через
  GitHub Actions → Artifacts, не через GitHub Releases.
