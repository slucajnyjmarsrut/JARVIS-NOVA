# JARVIS NOVA — управление только через чат (ветка `jarvis`)

## Главное окно

Основной интерфейс теперь устроен как чат: **напиши желание и нажми Enter**.
Кнопки режимов, отправки, скриншота, обновления, настроек и сворачивания
не занимают место по умолчанию. Для доступности остался резервный вызов
палитры команд по **F10** и мини-чата по **Ctrl+Shift+O**.
Во время загрузки Qwen остаётся видимой необходимая кнопка остановки.
Микрофон, распознавание речи и озвучивание ответов отсутствуют в
продукте. Звуковые дорожки видеомонтажа можно использовать без
записывающих устройств.

Поддерживаются, например:

- «Хочу смонтировать видео» → редактируемый таймлайн.
- «Хочу эдит» → готовые стили коротких роликов.
- «Хочу добавить озвучку к видео» → многодорожечный редактор.
- «Хочу написать программу на Python» → ИИ-разработчик с исходной задачей.
- «Хочу написать сайт» → HTML-проект в ИИ-разработчике.
- «Давай поспорим» → диалог в режиме аргументированной дискуссии.
- «Хочу показать скриншот» → безопасное окно выбора изображения.
- «Проверь обновления» → центр обновлений.
- «Установи Qwen» → проверка модели и запрос согласия на скачивание.
- «Хочу использовать FreeLLM» → выбор модели с согласием на внешнюю передачу.
- «Открой настройки» → резервная палитра.
- «Хочу открыть калькулятор» → проверенная команда запуска приложения.
- «Разреши управление ПК» → запрос подтверждения владельца.
- «Что ты умеешь» → подсказки в переписке, без меню.

Эти примеры — **маршрутизация к существующим инструментам**, а не
неограниченный автономный агент. Нестандартные фразы обрабатываются обычной
моделью Qwen/FreeLLM, но текст модели не становится командой ОС без проверки.
Рискованные действия требуют прежнего подтверждения: загрузка моделей,
управление/чтение экрана, тесты в Docker, запись программ, рендер,
публикация и установка обновлений.

Нельзя подменить подтверждение одной фразой «делай всё без вопросов».
Нет скрытых кликов, запуска неподтверждённого кода, записи или загрузки
в социальные сети. Полноценный разговор требует локальной Qwen или
отдельно разрешённого FreeLLM; базовые команды работают без модели.

## Проверка

`python -m unittest discover -s tests -p test_chat_first_intent.py -v`

`python scripts/run_text_only_tests.py`

В Windows Lite CI проверяется главное окно, текстовые маршруты и
упаковка. Новый код хранится исключительно в `jarvis`; `main` не меняется.
