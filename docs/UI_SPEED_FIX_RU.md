# JARVIS NOVA — исправление меню и видеостудии

Вместо светлого системного меню теперь **тёмная панель команд** с
группами «Разрешения», «AI», «Режимы» и всеми прежними действиями.
Панель автоматически прижимается к границам монитора. Нажми на ⚙ или F10,
на Esc — закрой. Действия с ПК и интернетом требуют прежних разрешений.

Видеостудия использует тёмную тему JARVIS NOVA, разделение на блоки,
двухколоночную сетку действий, скроллинг настроек и отдельную область
сценария. Кнопка **«Показать план съёмки»** теперь выводит все кадры
текстом. Кнопки «Копировать» и «Сохранить текст» реально работают, а
сохранение не перезаписывает существующие файлы.

## Ускорение сценариев

Выбирай один из трёх режимов:

- **⚡ Быстро — по умолчанию.** Создаёт тематический локальный сценарий
  без запуска нейросети или ожидания Qwen. Для тем «гитара/караоке»,
  Roblox/игры и готовки есть отдельные примеры последовательности кадров.
  Это честно помеченный шаблон, не AI.
- **AI · стандарт.** Просит локальную Qwen составить более индивидуальный
  сценарий; ограничение *HTTP-ответа* — 20 секунд. Первый запуск Ollama
  может занять дополнительное время. При сбое/неполном JSON — быстрый
  сценарий с предупреждением.
- **AI · подробно.** Больше текста/кадров; ограничение HTTP — 75 секунд,
  первая загрузка локальной модели также может занять дополнительное время.

Нейросеть иногда включает пояснения вокруг JSON. Код умеет извлекать
валидный JSON-объект из ответа без выполнения текста. Если формат
содержит ошибку — выдаёт понятное предупреждение, а не пустой экран.
В обоих AI-режимах локальная Qwen может использовать уже запущенный
Ollama из JARVIS, вместо повторного запуска для каждого сценария.

CSV **необязателен**, если пользователь задал тему. Статистика канала
используется для более точного предложения, но отсутствие CSV не
блокирует сценарий. Публичные Google Trends по-прежнему требуют
отдельного подтверждения и могут работать медленнее.

Код редактора FFmpeg, FilmCraft, Luau/Roblox и аудиодорожки видео не
затронут. Голосовой ввод и озвучивание JARVIS не добавлялись.

Инструкции по сборке и тестированию:
- tests/test_ui_speed_redesign.py
- .github/workflows/ui-speed-design.yml

Важно: время AI зависит от компьютера; никаких обещаний «2–4 секунды»
для реальной Qwen нет.
