# JARVIS NOVA — Видео-студия (экспериментальный модуль)

### Что делает

- По **отдельному согласию** загружает свежие поисковые запросы Google Trends через `https://trends.google.com/trending/rss?geo=RU`. Это сигналы интереса к темам, а не рейтинги TikTok/Reels или гарантия вирусности. Без согласия нет запросов в Интернет.
- Пишет **оригинальный** короткий сценарий через **локальную** мультимодальную `qwen3-vl:2b` (встроенный Ollama); если модель недоступна — показывает явно помеченный шаблон, не выдавая его за AI-анализ.
- Даёт по кадрам инструкции: что снять, сколько секунд, какой текст появится на экране. Может произнести инструкцию через работающую озвучку JARVIS.
- После съёмки пользователь кладёт **свои** видео в папку: `01.mp4`, `02.mp4` и так далее. В меню **Видео / Вирусные ролики** выбирает эту папку и подтверждает монтаж.
- Встроенный FFmpeg сшивает материал, сохраняет/создаёт аудиодорожку, приводит кадры к вертикальному 9:16 и накладывает крупные экранные подписи. Выдаёт MP4 и JSON-монтажный лист.
- Не публикует ролик автоматически, не копирует чужие видео, не скачивает музыку и не загружает исходники в облако. Публикация только после просмотра человеком.

### Ограничения

1. Чтобы смонтировать видео, пользователь сначала **снимает** кадры. JARVIS не может физически снять их вместо человека.
2. Это первая версия: кадры склеиваются **по заданному порядку файлов**, без автоматического поиска самых зрелищных моментов на всех дублях.
3. Экранные подписи — **тексты сцен**, а не автоматически выровненная по словам транскрипция речи. Генерации музыки и авто-публикации нет.
4. Интерфейс / Windows PyInstaller / встроенный FFmpeg в новом установщике требуют **новой сборки и E2E**, старый DEV-установщик от 18 октября **не содержит этой функции**.
5. RSS может быть недоступен по сети, в некоторых странах и по отдельным темам трендов может не быть. Сценарий тогда создаётся без заявления о «свежем тренде».
6. Авторские права на чужой звук и видео необходимо соблюдать. Для коммерческих TikTok публикаций использовать подходящую разрешённую музыку.

### Данные и безопасность

- Все отснятые кадры остаются в исходной папке без перезаписи. Монтажные результаты и сценарии — `%LOCALAPPDATA%\\JarvisNova\\viral_studio`.
- FFmpeg/ffprobe вызываются только как отдельные процессы с параметрами-списками, без shell-кода.
- Отмена операции и закрытие окна прерывают обработку; опубликования без подтверждения нет.
- Для скачивания FFmpeg в CI используется зафиксированный SHA-256 бинарного архива BtbN. Лицензию GPL (сборка с libx264), перечень сторонних библиотек и условия распространения нужно приложить до публикации новой сборки.

### Разработчику

```powershell
python -m unittest discover -s tests -p test_viral_studio.py -v
./scripts/prepare_ffmpeg.ps1
```

Для настоящего теста монтажа тест создаёт два цветных ролика и конвертирует их в короткий MP4; без ffmpeg тест будет пропущен.
