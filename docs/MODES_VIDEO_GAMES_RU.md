# JARVIS NOVA — режимы роликов, выбор игры, очистка интерфейса (DEV)

## Как включить

- «Джарвис, включи игровой режим» → вопрос **«В какую игру хочешь поиграть?»**. Следующая фраза с названием (например, «Portal 2») проверяется по меню Пуск или локальным Steam manifest-файлам, а запуск происходит только после подтверждения. «Сменить игру», «начни сессию», «отмена» работают в игровом режиме. Неизвестные игры/пути/системные оболочки не запускаются. Steam распознаётся только по локальной библиотеке, а не по сетевому API.
- «Включи режим роликов» → Видео-студия, **сначала аудитория и CSV**, без скрытого доступа к каналу.
- «Включи режим съёмки» → сценарий и голосовой список кадров.
- «Режим монтажа» → сборка вертикального видео из собственных роликов.
- «Включи режим оценки» → послемонтажная оценка соответствия аудитории канала.

Во всех режимах роликов фразы «проанализируй канал», «напиши сценарий», «что снимать», «смонтируй ролик», «оцени ролик» запускают соответствующий *уже существующий* этап Видео-студии с его проверками/подтверждениями. **Включение режима само по себе ничего не публикует, не скачивает и не монтирует.**

## Что чистилось

- В меню «Режимы» собраны обычные и видеорежимы; дублирующий отдельный пункт «Видео / Вирусные ролики» убран.
- Удалён дублирующий импорт голосового движка в `main.py`.
- Игровой режим больше не открывает Steam и Discord без выбора конкретной игры.
- Игровой каталог получает только читаемые сведения об уже установленных играх; ID Steam перепроверяется перед запуском.
- Кнопка «Настроить приложения» относится только к режимам Работа, Офис, Учёба и не предлагает назначать произвольные EXE для видео/игр.
- Очистка **не удаляет** пользовательские материалы и статистику, настройки, модели, проекты, сценарии или прошлые рендеры.

## Доказательства и ограничения

Модульные тесты проверяют переходы режимов, отсутствие автоматического запуска, распознавание manifest, подтверждение Steam и ранее сделанный настоящий FFmpeg рендер. Это ещё не физическое испытание микрофона, игр и редактора на Windows. Старый опубликованный DEV-установщик был собран **до этих изменений**. Новый сборочный workflow должен включить FFmpeg и обновлённые Python-модули.
