# JARVIS NOVA Python Agent RC1 — состояние сборки

Дата подготовки: 2026-10-16

**Факт:** исходный проект с механизмом одной Windows PyInstaller-сборки готов,
но Windows EXE из него в этой среде НЕ получен.

### Реализовано
- Встроенная в проект модель Vosk (91,3 МБ до архивации).
- Голосовая активация с резервным Whisper на коротких сегментах.
- Синтез Silero с системным Windows TTS при ошибке, планировщик с разрешениями.
- Управление установленными программами, экраном, мышью и клавиатурой.
- Локальное зрение при отдельно доступной Ollama с vision-моделью.
- GUI без PowerShell и создание единого Windows EXE через PyInstaller.

### Проверено здесь
- Python syntax/compileall.
- 24 unit-теста: маршрутизация, ограничения, разрешения, Whisper с имитацией
  ответов модели, запрещённые AI-действия.
- Проверка структуры скриптов и готовности всех ресурсов Vosk.
- Комплект для GitHub Actions: проверка SHA Whisper, Silero audio generation,
  load-model Whisper/Vosk, упаковка, контрольная сумма.

### Не проверено здесь
- Windows PyInstaller, реальный микрофон, реальное распознавание Whisper,
  Silero на Windows, управление окнами, AI vision и размер итогового EXE.
- Настоящая модель зрения не встроена.
- Ограниченный агент не умеет выполнять любые действия в произвольной программе.

### Препятствие
Сессия работает на Linux, Wine/Windows SDK/PyInstaller отсутствуют,
прямые сетевые загрузки моделей и пакетов заблокированы по DNS.
Сборка EXE должна идти на Windows-раннере в GitHub Actions либо Windows-ПК.
Скрипт подготовлен, но задача на внешнем раннере не запускалась.
