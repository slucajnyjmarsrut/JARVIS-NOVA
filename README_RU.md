# JARVIS NOVA — текстовый помощник для Windows

Рабочая ветка: `jarvis`. Главный экран — тёмная компактная переписка.
Ввод только текстом, отправка клавишей Enter.

JARVIS выбирает существующие встроенные функции по сообщению в чате:
Qwen/FreeLLM, монтаж двухчасовых исходников в 15-минутный ролик,
автосборку и проверку многомодульных программ, Roblox, проверенные команды
Windows, работа с изображениями и режим аргументированного спора.

**В установленном приложении отсутствуют микрофон, распознавание речи
и озвучивание ответов.** Не устанавливаются речевые зависимости и
модели; исторический код, не связанный с текущей сборкой, остаётся
только в репозитории. Звуковые дорожки видеомонтажа — отдельная
функция обработки файлов, не голосовой ассистент.

Для разрешений, доступа к экрану, экспорта, записи кода и обновлений
сохраняется подтверждение. Настройки можно открыть командой в чате
или клавишей F10, мини-чат — Ctrl+Shift+O.

Подробно: [управление только чатом](docs/CHAT_FIRST_RU.md).
Точка входа Windows: `bootstrap.py` → `text_only_main.py`.
