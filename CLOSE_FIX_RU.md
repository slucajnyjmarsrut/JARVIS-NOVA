# Исправление крестика — Python Agent RC2

Кнопка X (`WM_DELETE_WINDOW`) теперь устанавливает флаг завершения и убирает разрешения, отключает микрофон, прекращает озвучивание, удаляет окно и не переводит приложение в трей. Если нативные аудио/AI-потоки остаются жить, предусмотрен аварийный выход через 5 секунд. Загрузка Silero и Vosk больше не должна снова запускать микрофон, если окно уже закрыто. Все фоновые потоки агента — daemon; сторонние приложения, которые пользователь открыл через JARVIS, не закрываются.

Это **проект PyInstaller, а не готовый Python EXE**: для сборки на Windows нужен workflow GitHub Actions из `.github/workflows/build-exe.yml` и загрузка моделей на машину сборки. Тесты Python выполнялись на Linux, закрытие реального окна Windows ещё не подтверждено.
