# JARVIS NOVA — Windows offline voice assistant

Проект локального голосового ИИ-помощника для Windows 10/11 x64.

**Статус: разработка. Полностью автономный Windows EXE НЕ готов и НЕ подтверждён реальными испытаниями.**

## Цель

Один установочный EXE с настоящими локальными моделями Whisper (русское ASR), Vision (понимание кадра камеры/экрана), Silero TTS и голосовой активацией «Джарвис». Никакого ручного Python или скачивания моделей на компьютере конечного пользователя.

## Исходные ветки из transfer kit

- Go 3.6.2: Windows-команды и Vosk, но без Whisper/Vision/Silero.
- Python Agent RC4: интерфейс, действия Windows, PyInstaller, локальное обучение.
- Stage 2: отдельный речевой цикл Whisper → Vision → Silero.

Основная линия объединения — Stage 2 и RC4. Go-ветка — функциональный ориентир.
