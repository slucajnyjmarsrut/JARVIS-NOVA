# JARVIS NOVA — текстовый помощник Windows

Рабочая ветка: `jarvis`. Основной интерфейс — тёмное окно переписки
с полем ввода; сообщение отправляется клавишей Enter.

В приложении: локальная Qwen, добровольно подключаемый FreeLLM,
проверенные команды Windows, написание кода, Roblox, видео-редакторы,
анализ экрана только с разрешения и аргументированный режим дискуссии.

## Управление

Напиши задачу в чат. Для известной функции JARVIS открывает нужный
встроенный редактор. Обычный разговор идёт через выбранную модель.
Разрешения на действия, экспорт и запись файлов запрашиваются отдельно.
Для резервного меню есть F10; для мини-чата — Ctrl+Shift+O.

**Речевых функций у устанавливаемого JARVIS нет.** Приложение не
запрашивает доступ к записывающим устройствам и не воспроизводит
озвученные ответы. Звук внутри видеоредактора относится только к
монтажу медиафайлов. Сохранённые исторические исходники не включаются
в Windows-приложение.

## Сборка

Главная точка входа: `bootstrap.py` → `text_only_main.py`.
Windows PyInstaller: `jarvis_nova.spec`, без речевых библиотек и
моделей. Тесты продукта: `python scripts/run_text_only_tests.py`.

Состояние сборок: [GitHub Actions](https://github.com/slucajnyjmarsrut/JARVIS-NOVA/actions?query=branch%3Ajarvis).
Документация: [управление чатом](docs/CHAT_FIRST_RU.md).
Ветка `main` не изменяется автоматически.
