# JARVIS NOVA — автономный голосовой помощник Windows

**Актуальная линия разработки: 0.5.18-dev** в рабочей ветке `jarvis`, Windows 10/11 x64, русский язык.
Код версии 0.5.18 перенесён из `fix/learning-data-preservation-2026-10` с сохранением истории. Ветка `main` остаётся на более старой версии.

> **Передача проекта в новый чат / новую GitHub-ветку:**
> [Полная инструкция на русском — текущее состояние, архитектура, права, запреты и план работ](docs/START_NEW_CHAT_JARVIS_NOVA_RU.md).

## Что входит

- Активация «Джарвис» или **F9**; непрерывный локальный Vosk wake, **Whisper base** (быстрый первый проход) и **Whisper small** (уточнение сомнительных фраз или режим максимальной точности).
- Интеллектуальная чувствительность тихого микрофона, обнаружение фраз, очистка и нормализация, перенастройка USB/Bluetooth-аудио при обрыве.
- Локальная **Qwen/Ollama** для разговоров, **Silero** для русской озвучки, тихие ответы на шепотоподобную речь.
- Тёмный NOVA HUD, **левая** основная панель и левый оверлей, тёмная полоса прокрутки, настройка чувствительности, строка «РАСПОЗНАНО».
- Безопасные ограниченные команды Windows с пользовательскими разрешениями и подтверждениями, режимы Игры / Работа / Офис / Учёба.
- Локальный анализ **экрана только с разрешения** и отдельная видеостудия для готовых файлов через FFmpeg.
- **Веб-камера полностью удалена**. Никаких webcam backend и `opencv-python` для захвата камеры.

## Быстрое распознавание (ветка `jarvis`, октябрь 2026)

- По умолчанию — **«Сбалансировано»**: команда после «Джарвис» или F9 сначала идёт через Whisper base; Small запускается только при сомнительном распознавании. Для максимальной точности оставлен отдельный режим Small, а для слабого процессора — Base.
- Для точности после активации восстановлено **900 мс** тишины: 700 мс иногда обрывают окончания русских слов. Предзапись перед началом речи увеличена с 700 мс до 1 секунды.
- Чувствительность тихого микрофона по умолчанию повышена с 1.0 до **1.2** (вручную регулируется 0.75–2.0); звук не сохраняется.
- Сбалансированный режим уточняет через Small и уверенный результат Base, который **сильно расходится с Vosk при подтверждённом обращении**. Vosk не подменяет команду и не предоставляет разрешения.
- Ограничение генерации короткого голосового ответа Qwen уменьшено до 56 токенов. Это не ускоряет запуск холодной модели и не гарантирует конкретное время ответа.
- Проверка качества: НАСТРОЙКИ / F10 → Распознавание речи; произнести 3 фразы, сверить «РАСПОЗНАНО» и субъективную задержку до ответа. При ошибках на сложных названиях вручную выбрать «Точнее русский · Whisper small».
- **Защита от пропавших аудиоблоков**: если PortAudio сообщает о переполнении входа или очередь микрофона вынужденно пропустила пакет, JARVIS сбрасывает текущую фразу, не объединяет обрывки в ложную команду и показывает «Микрофон пропустил часть звука». При повторении проблемы проверить нагрузку CPU, выбранное устройство и драйвер микрофона. Сырые звуковые записи не сохраняются.
- Автотесты проверяют логику выбора модели и обнаружение пропусков PCM, но качество настоящего микрофона, шумоподавление и задержки на конкретном CPU требуют измерений.

## Что ещё требуется

1. **Реальные тесты русского ASR на пользовательском микрофоне**: F9, три русские фразы, сравнить `РАСПОЗНАНО` со сказанным.
2. Измерения задержек capture/VAD → Whisper → Qwen → Silero на физическом Windows ПК.
3. Проверка цветов, высоты левой панели и читаемости при масштабировании экрана.
4. Подготовка регулярных GitHub Releases с учётом большого размера офлайн-пакета.

Все действия с ПК и кадрами экрана требуют соответствующих разрешений внутри JARVIS; автономный разговорный режим не отправляет речь в облако. Подробности и правила развития — в [полной передаче](docs/START_NEW_CHAT_JARVIS_NOVA_RU.md).
