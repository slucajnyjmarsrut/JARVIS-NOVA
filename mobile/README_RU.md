# JARVIS NOVA Mobile — Android MVP (не финальный релиз)

Этот модуль — первое отдельное Android-приложение с **настоящими системными телефонными действиями**, но **НЕ** готовый помощник для непрерывного прослушивания при заблокированном экране.

## Уже реализовано в Android-коде

- Поле команд и кнопка системного голосового ввода `RecognizerIntent` (требуется установленный распознаватель в системе; пожелание offline не гарантирует offline).
- «Джарвис, позвони маме»: разрешение на чтение контактов, выбор подходящего контакта и открытие системной звонилки через `ACTION_DIAL`. Пользователь подтверждает реальный звонок самостоятельно; при блокировке ОС может потребовать разблокировку.
- «Включи музыку», «пауза», «следующий трек», «предыдущий трек»: управление **уже активной** медиасессией, если владелец включил Notification Access для JARVIS; сервис уведомлений не читает и не сохраняет их содержимое.
- Без разрешения нет чтения телефонной книги, без доступной медиасессии нет несанкционированного запуска плееров, без прямого подтверждения нет телефонного вызова.
- Добавлен **экспериментальный** HTTPS-клиент для проверки статуса локального ПК. Он не отправляет содержимое телефона и не выполняет команды на компьютере.

## Чего пока НЕТ

1. **Wake word «Джарвис» с заблокированным экраном.** Требует системного роли Assistant, `VoiceInteractionService` и `VoiceInteractionSessionService`, согласия владельца и проверок на конкретных версиях Android. Обычный background microphone foreground service нельзя просто запустить после блокировки или перезагрузки; Android 14+ ограничивает такие сценарии.
2. **Звонка голосом без касаний из заблокированного состояния.** Системные возможности зависят от настроек блокировки, статуса системного помощника и политики OEM. Не обходим PIN, биометрию, UAC-подобные ограничения.
3. Выбора конкретного плейлиста стороннего приложения. Здесь доступна только управление активной медиасессией; для выбора треков нужна интеграция API выбранного плеера.
4. Удалённого просмотра роликов с ПК. Есть только отдельный опциональный read-only сервер статуса ПК с TLS, сертификатом SHA-256 и 256-битным токеном. Передача MP4 и управление ПК ещё НЕ реализованы.
5. iOS сборки, уведомлений и офлайн Whisper на устройстве.

## Сборка

`cd mobile/android && gradle :app:assembleDebug` (Gradle 8.9, JDK 17, Android SDK 35). GitHub Actions собирает и тестирует APK отдельно от тяжёлого Windows EXE.

Проверка поведения на настоящем Android-телефоне обязательна. APK для разработчика — не проверенный релиз.

## Следующий шаг для заблокированного экрана

Реализовать системную роль Assistant и минимальный `VoiceInteractionService` с распознаванием hotword при поддержке ОС, затем опциональное подтверждение контакта голосом. Использовать Android Telecom/системную звонилку, не запускать вызов через UI automation. Для iOS — отдельно Siri/App Intents; нельзя обещать собственное фоновое «Джарвис» вне ограничений iOS.

## Защищённый канал с ПК — экспериментальный прототип

Это **не автоматическое сопряжение**, не работа с телефоном при заблокированном экране и не доступ к файлам ПК. На ПК отдельно, вручную запускается `mobile/pc_link_server.py`; штатный JARVIS его сам не запускает. Сервер имеет один read-only запрос `GET /v1/status` и **не принимает команд на выполнение**.

Для теста на локальном ПК, где установлен Python 3.11+, нужны OpenSSL, разрешённый частный IPv4 адрес компьютера и TLS-сертификат с SAN именно этого IP. Пример для адреса 192.168.1.10 (замените его на действительный адрес вашего ПК):

```powershell
openssl req -x509 -newkey rsa:3072 -sha256 -days 30 -nodes -keyout pc-link-key.pem -out pc-link-cert.pem -subj "/CN=JARVIS NOVA PC" -addext "subjectAltName=IP:192.168.1.10"
python -c "import secrets; from pathlib import Path; Path('pc-link-token.txt').write_text(secrets.token_hex(32), encoding='ascii')"
python mobile/pc_link_server.py --bind 192.168.1.10 --port 8443 --cert pc-link-cert.pem --key pc-link-key.pem --token-file pc-link-token.txt
```

Секрет и приватный ключ **никогда не загружайте в GitHub**, храните в защищённой пользовательской папке и ограничьте права чтения. Правило Windows Firewall должно разрешать входящий порт 8443 только из вашей частной сети или IP телефона. Публичный интернет, внешний IP, открытие портов роутера и HTTP не поддерживаются.

Сервер выводит публичный SHA-256 отпечаток сертификата. На телефоне введите HTTPS-адрес, отпечаток и 64-символьный токен из файла **по доверенному локальному каналу**. Android проверяет совпадение сертификата, имя/IP в сертификате, токен и запрашивает статус через TLS. Неверный отпечаток или токен не позволяют подтвердить связь. Поля токена не сохраняются приложением в настройки и не попадают в Android Backup.

**Ограничения:** пока нет QR-сопряжения, управления компьютером, обмена файлами, фонового соединения, автоматической ротации секретов и испытания на двух реальных устройствах. Успешный APK-тест проверяет код и правила безопасности, но не физическую сеть или Android microphone.
